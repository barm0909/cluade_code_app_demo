# 原価履歴タブ

**仕入単価の推移**を確認するための**見るだけの画面**です。入荷予定に入力した仕入単価が、
実際に入荷したときの記録として積み上がっていく様子を一覧します。

「この商品、この仕入先から前はいくらで仕入れていたか」「最近値上がりしていないか」を
確認するための画面で、この画面から何かを入力・変更することはできません。

この画面で在庫が動くことはありません。何を押しても記録は増えません。

---

## 1. 画面の構成

```
[商品名・SKU・仕入先で検索...] [開始日 〜 終了日] [仕入先▼] [条件クリア]
─────────────────────────────────────────────────────
3件   平均仕入単価 ¥152   仕入金額合計 ¥4,560
                        [CSVエクスポート（原価履歴）]
─────────────────────────────────────────────────────
日時 商品名 SKU ロットNo 仕入先 仕入単価 前回比 数量 金額
2026/08/10 09:00  牛乳  ML-001  20260910  山田乳業  ¥120  ▲¥2  10  ¥1,200
2026/08/05 09:00  食パン BR-001  20260805  朝日ベーカリー  ¥200  初回  5  ¥1,000
2026/08/01 09:00  牛乳  ML-001  20260901  山田乳業  ¥118  初回  10  ¥1,180
```

一覧は**新しい順**に並びます。

### 絞り込み

| 条件 | 対象 |
|------|------|
| キーワード | 商品名・SKU・仕入先名の部分一致 |
| 期間 | 記録日時（開始日・終了日とも、その日を含む） |
| 仕入先 | 仕入先マスタに登録された仕入先 |

### 集計（絞り込み後）

| 項目 | 内容 |
|------|------|
| 件数 | 表示中の記録の件数（絞り込み中は「/ 全N件」も表示） |
| 平均仕入単価 | 表示中の記録の**数量で加重平均**した単価（`仕入金額合計 ÷ 数量合計`） |
| 仕入金額合計 | `仕入単価 × 数量` の合計 |

---

## 2. どの記録が並ぶか

**入荷予定に仕入単価を入力したうえで「入荷」した記録だけ**が並びます。

- 入荷予定タブで仕入単価を空欄（0円）のまま入荷した記録は、履歴として意味がないため**並びません**。
- 在庫一覧タブの「入庫」やロット編集、棚卸、Excelインポートなど、**入荷予定を経由しない入荷**は
  仕入単価を持たないため、この画面には出てきません。
- 一件も記録がない場合は、案内文だけが表示されます。

## 3. 前回比

**同じ商品を同じ仕入先から仕入れた、ひとつ前の記録**と比べた差額です。

| 表示 | 意味 |
|------|------|
| ▲¥N | ひとつ前より値上がり |
| ▼¥N | ひとつ前より値下がり |
| ±0 | ひとつ前と同じ単価 |
| 初回 | その商品×仕入先の組み合わせで最初の記録（比べる相手がない） |

商品が違う、または仕入先が違う記録とは比較しません（値上がり・値下がりの判定を混同しないため）。

## 4. CSVエクスポート

「CSVエクスポート（原価履歴）」で、**絞り込み後の一覧**を `原価履歴_YYYY-MM-DD.csv` に出力します。

```
日時,商品名,SKU,ロットNo,仕入先,仕入単価,前回単価,数量,金額
2026/08/10 09:00,牛乳,ML-001,20260910,山田乳業,120,118,10,1200
2026/08/05 09:00,食パン,BR-001,20260805,朝日ベーカリー,200,,5,1000
```

---

## 5. 注意点

- **商品マスタの「原価」はこの画面から変わりません。** 原価履歴はあくまで「過去にいくらで
  仕入れたか」の記録です。値上がりに気づいたら、商品マスタで原価を手動で見直してください。
  （なお、入荷した**そのロット自体**の原価は入荷のたびに自動で更新されます。棚卸・廃棄ロス・
  ダッシュボードの在庫金額はロットの原価を優先して使うので、実際の評価額はこの画面を見なくても
  自動的に正確になっています。詳しくは [inventory.md](inventory.md) の「原価」欄を参照してください）
- **誰が操作したかは記録されません**（ログイン機能がないため）。
- ヘッダーの「リセット」を押すと帳票も消えるため、原価履歴もなくなります。

### 開発者向けメモ

- 画面：`src/CostHistoryView.tsx`（絞り込み条件だけがローカル状態）
- 計算：`src/useInventory.ts` の `costHistoryRows` / `filterCostHistory` / `costHistoryTotals` /
  `costHistoryCsv` / `exportCostHistoryCsv`
- 専用の保存データはなく、既存の帳票（`ledger`）から集計。仕入単価そのものは入荷予定
  （`InboundPlan.unitPrice`）に入力し、入荷時に帳票（`StockTransaction.unitPrice` / `supplierId`）へコピーされる
- 詳しい設計は [../cost-history-feature.md](../cost-history-feature.md)
