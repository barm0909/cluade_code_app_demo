# 商品マスタタブ

商品・カテゴリ・倉庫・仕入先という**基礎データ（マスタ）**を整えるための画面です。
1つのタブに4つのセクションが縦に並びます。

```
[+ 商品追加]
 ── 商品マスタ（一覧＋インライン編集）
 ── カテゴリマスタ
 ── 倉庫マスタ
 ── 仕入先マスタ
```

在庫数はこの画面では扱いません（在庫の増減は在庫一覧タブ・棚卸タブで行います）。

---

## 1. 商品マスタ

登録済みの商品を一覧し、その場（行の中）で編集できます。

| 列 | 内容 |
|----|------|
| 商品名 / SKU / JANコード / カテゴリ | 商品の識別情報 |
| 最低在庫数 | 発注点。合計在庫がこの数以下になると要発注として警告されます |
| 販売定価 / 原価 | 円単位 |
| 操作 | 編集 / 削除 |

### + 商品追加

在庫一覧タブと同じ商品追加ダイアログが開きます。追加した商品はロットを持たない（在庫0の）状態で登録されます。
在庫を入れるには、在庫一覧タブでその商品を展開して「+ ロット追加」を行ってください。

### 編集（インライン編集）

「編集」を押すとその行が入力欄に変わり、「保存」で確定、「キャンセル」で破棄します。
一度に編集できるのは1行だけです。

**入力チェック**

| 条件 | 表示されるエラー |
|------|------------------|
| 商品名またはSKUが空 | 商品名とSKUは必須です |
| JANコードが8桁でも13桁でもない | JANコードは数字8桁または13桁で入力してください |

JANコードは入力しながら自動整形されます（全角数字→半角、ハイフンや空白は削除、13桁で打ち止め）。
バーコードリーダーやIMEオンのままの入力でも、そのまま入れて問題ありません。空欄のままでも保存できます。

### 削除

商品と、その商品のロット（在庫）がすべて消えます。確認ダイアログが出ます。
在庫が残っていたロットは「調整出庫（備考：商品削除）」として帳票に記録されます。

---

## 2. カテゴリマスタ

商品の分類を管理します。カテゴリは絞り込みと集計に使われます。

| 列 | 内容 |
|----|------|
| カテゴリ名 | 分類の名前 |
| 使用商品数 | そのカテゴリに属している商品の件数 |
| 操作 | 編集 / 削除 |

- **追加**：上の入力欄に名前を入れて「+ カテゴリ追加」。空欄では追加されません。
  **すでに同じ名前のカテゴリがある場合は、何も起きません**（エラーメッセージは出ません）。
- **編集**：行の「編集」で名前をその場で変更し「保存」。
  商品はカテゴリを名前ではなく内部IDで参照しているため、**改名すると全画面の表示が一斉に変わります**
  （商品を選び直す必要はありません）。他のカテゴリと同じ名前への変更は反映されません。
- **削除**：**使用商品数が0のカテゴリだけ**削除できます。1件でも使われていると削除ボタンが押せず、
  マウスを乗せると「使用中のカテゴリは削除できません」と表示されます。
  → 先に商品側のカテゴリを付け替えてから削除してください。

---

## 3. 倉庫マスタ

在庫の置き場所を管理します。初期状態では次の3つが登録されています。

| 倉庫名 | 用途例 |
|--------|--------|
| 販売倉庫 | 通常販売用の在庫（ロット登録時の初期値） |
| 保留倉庫 | 検品中・一時保管の在庫 |
| 不良倉庫 | 破損・期限切れなど販売不可の在庫 |

| 列 | 内容 |
|----|------|
| 倉庫名 | 色つきバッジで表示 |
| カラー | 一覧やダッシュボードで倉庫を見分けるための色 |
| 使用ロット数 | その倉庫に置かれているロットの件数 |
| 操作 | 編集 / 削除 |

- **追加**：倉庫名と色を指定して「+ 倉庫追加」。名前が空では追加されません（前後の空白は自動で取り除かれます）。
- **編集**：名前と色をその場で変更。ロットは倉庫を内部IDで参照しているため、
  **改名・色変更は全画面（バッジ・絞り込み・帳票の倉庫列）に即時反映されます。**
- **削除**：**使用ロット数が0の倉庫だけ**削除できます。使用中は「ロットが使用中の倉庫は削除できません」と表示され、押せません。
  → 先にロットを別倉庫へ移動してから削除してください。

---

## 4. 仕入先マスタ

発注先を管理します。入荷予定の「仕入先」はここに登録したものから選びます
（以前の自由入力ではなくなりました）。

| 列 | 内容 |
|----|------|
| 仕入先名 | 取引先の名前。備考があれば名前の下に小さく表示されます |
| コード | 仕入先コード（社内・基幹システムの取引先コードなど）。空欄でも構いません |
| 担当者 | 先方の担当者名 |
| 連絡先 | 電話番号とメールアドレス |
| リードタイム | 発注してから届くまでの標準日数 |
| 入荷予定 | この仕入先の予定件数。入荷待ちがあれば件数と数量、予定日を過ぎていれば「遅延◯」が付きます |
| 状態 | 取引中 / 取引停止 |
| 操作 | 編集 / 取引停止（再開） / 削除 |

上部の検索欄で**仕入先名・コード・担当者・電話・メール**を部分一致で絞り込めます。
「取引停止も表示」のチェックを外すと、取引中の仕入先だけになります。
「CSVエクスポート（仕入先一覧）」で、表示中の内容をそのまま書き出せます。

### 追加・編集

「+ 仕入先追加」または行の「編集」でダイアログが開きます。入力項目は
**仕入先名・コード・担当者・電話番号・メールアドレス・住所・標準リードタイム・取引状態・備考**で、
必須は仕入先名だけです。

**入力チェック**

| 条件 | 表示されるエラー |
|------|------------------|
| 仕入先名が空 | 仕入先名は必須です |
| 他の仕入先と同じ名前 | 同じ名前の仕入先がすでにあります |
| 他の仕入先と同じコード（空欄どうしは重複になりません） | 同じ仕入先コードがすでにあります |
| メールアドレスの形式が不正（空欄は対象外） | メールアドレスの形式が正しくありません |

**標準リードタイム**は、入荷予定を新しく作るときの入荷予定日の初期値（今日＋日数）に使われます。
入荷予定の画面で自分で日付を入れ直したあとは、仕入先を変えても日付は動きません。

仕入先は入荷予定から**名前ではなく内部IDで参照**されているため、**改名すると全画面の表示が一斉に変わります**。
ただし、すでに入荷した分の帳票の備考（`入荷予定（仕入先名）`）は**入荷した時点の名前のまま**残ります。

### 取引停止 / 取引再開

取引が終わった仕入先は、削除ではなく「取引停止」にしてください。

- 一覧には淡い色で残り、過去の入荷予定の仕入先も表示されたままになります
- **新しい入荷予定の仕入先の選択肢からは外れます**
  （すでにその仕入先を指している予定を編集するときだけは選択肢に残ります）

「取引再開」を押すと元に戻ります。

### 削除

**入荷予定が1件もない仕入先だけ**削除できます（キャンセル済み・入荷済みの予定も「使用中」に数えます）。
使われている場合は削除ボタンが押せず、マウスを乗せると
「入荷予定で使用中の仕入先は削除できません（取引停止にしてください）」と表示されます。

---

## 5. マスタを変更するときの注意

- **カテゴリ・倉庫・仕入先の改名は安全です。**過去の帳票や在庫・入荷予定の紐づけが切れることはありません。
- **商品のSKUを変えると、Excelインポートの突き合わせが変わります。** インポート用のファイルも合わせて更新してください。
- **削除は元に戻せません。**特に商品の削除は在庫ごと消えるため、棚卸や帳票の突き合わせが終わってから行ってください。
- 過去の帳票には商品名・SKUが**記録された時点の値のまま**残ります。商品を改名しても過去の帳票の表示は変わりません。
