# 返品（売上返品・仕入返品）

返品には2種類あり、それぞれ別の画面から登録します。どちらも **在庫が動くので、入出庫帳票に必ず記録されます。**

| 種類 | どんなときか | 登録する場所 | 在庫 | 帳票の区分 |
|------|--------------|--------------|------|------------|
| **売上返品** | 得意先から商品が戻ってきた | 売上管理タブの明細の「返品」 | 増える | 売上返品（入庫 +） |
| **仕入返品** | 仕入先へ商品を返す | 在庫一覧タブのロット行の「返品」 | 減る | 仕入返品（出庫 −） |

返品は、在庫一覧の「入庫」「出庫」の区分としては選べません。元の売上やロットにひもづけて記録するため、
上の専用の画面からだけ登録します。

---

## 1. 売上返品

売上管理タブの **明細** で、返品したい売上の行の「返品」を押します。

```
元の売上
  2026/09/23 07:48 / みどりストア
  牛乳（ML-001） ロット 20260914
  売上数量 8 / 返品できる数量 8

返品数量      [ 8 ]          ← 初期値は返品できる数量すべて
戻し先の倉庫  [販売倉庫 ▼]   ← 初期値は元の売上の出庫元
備考          [        ]     ← 空欄なら「売上返品（得意先名）」

ロット 20260914（期限 2026-09-14） に 8個 戻します（既存のロットに加算）
差し引く売上 ¥1,424（税抜）+ 消費税 ¥114 = 税込 ¥1,538
```

### 在庫の戻り方

- **元の売上と同じロットNo** のロットに戻します。戻し先の倉庫に同じロットNo・賞味期限のロットがあればそこへ足し、
  なければ新しいロットを作ります（賞味期限は同じロットNoのロットから、残っていなければロットNoの日付から復元します）
- 戻したロットの原価は、**売れたときのロットの原価** です
- 売り物にならない返品（破損・期限切れなど）は、戻し先を **保留倉庫・不良倉庫** にしてください。
  そのあと必要ならダッシュボードやロット行から廃棄します

### 売上への反映

- 売上返品は、売上管理の明細に **「返品」の印つきのマイナスの行** として並びます
- 単価・得意先・原価・消費税率は **元の売上と同じ** なので、売上高・消費税・原価・粗利がちょうどその分だけ差し引かれます
- 売上高のカードには「うち返品 ○件 −¥○」と返品の分も表示します
- 元の売上の行には「返品済 ○」と返品した数が出ます。**全部返品した売上は「返品」ボタンが押せなくなります**
- 得意先マスタの売上件数には返品を数えません（金額・粗利だけ差し引きます）

### 請求書・納品書

- **請求書** には、期間内の返品がマイナスの行（「返品」の印つき）として載り、請求額から差し引かれます
- **納品書** には返品を載せません（納品書は届けたものの書類のため）

### 返品できる数量

1件の売上について、**売上数量 − これまでに返品した数量** までです。超える数量は入力できません。

## 2. 仕入返品

在庫一覧タブで商品行を展開し、返品したいロットの行の「返品」を押します（在庫0のロットでは押せません）。

| 入力欄 | 内容 | 初期値 |
|--------|------|--------|
| 返品先の仕入先 | 必須。取引停止の仕入先は選べません | そのロットを入荷したときの仕入先（入荷予定から入荷した記録があるとき） |
| 返品数量 | 1以上、そのロットの在庫以下 | ロットの在庫すべて |
| 返品単価（税抜） | 任意。0は未入力 | ロットの原価 |
| 備考 | 任意 | 空欄なら「仕入返品（仕入先名）」 |

「返品する」を押すと、そのロットの在庫が減り、帳票に「仕入返品」が1件記録されます。在庫が0になったロットは
ほかの出庫と同じく **0のまま残ります**。

- ロットを「ロット追加」で直接登録した場合など、入荷の記録に仕入先がないときは、返品先を選んでから登録します
- 仕入返品は **入荷予定の入荷済数量を戻しません**（もう一度届く予定なら、入荷予定を新しく登録してください）
- 原価履歴には載りません（原価履歴は入荷の単価の記録です）

---

## 3. ほかの画面への影響

| 画面 | 売上返品 | 仕入返品 |
|------|----------|----------|
| 入出庫帳票 | 区分「売上返品」（入庫 +） | 区分「仕入返品」（出庫 −） |
| ロット追跡 | 入庫として並ぶ | 出庫として並ぶ |
| 売上管理 | マイナスの売上 | 関係なし |
| 在庫分析 | 出庫数・売上数から差し引く（期間内の返品が多くてもマイナスにはしない） | **出庫数に数えない**（需要ではないため） |
| 受注 | 出荷済数量は戻さない | — |
| 入荷予定 | — | 入荷済数量は戻さない |

---

## 4. 注意点

- 返品の **取り消しはできません**。間違えた場合は在庫一覧の「入庫」「出庫」（調整入庫・調整出庫）で在庫を直してください
  （売上は戻らないので、売上返品の取り消しは同じ売上をもう一度登録する必要があります）
- 売上返品は、元の売上が帳票にあるものだけです。商品ごと削除した売上は在庫に戻せないため、返品できません
- 仕入返品の返品単価は、記録として残すだけです（入金・相殺の管理はありません）
