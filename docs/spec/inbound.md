# 入荷予定タブ

**発注済みでまだ届いていない在庫**を登録しておき、実際に届いたときに
その予定から在庫（ロット）を作る画面です。

「いつ・何が・いくつ届く予定か」を見える化し、届いたら**予定の内容そのままで入庫**できるので、
毎回ロットNoや賞味期限を手入力する必要がなくなります。

> **入荷予定は在庫ではありません。** 予定を登録しただけでは在庫数は1つも増えません。
> 在庫が増えるのは「入荷」ボタンを押したときだけです（そのとき入出庫帳票にも記録されます）。

---

## 1. 画面の構成

```
[検索] [予定日 〜 予定日] [状態▼] [倉庫▼] [条件クリア]
─────────────────────────────────────────────────────
3件  予定 1,044  入荷済 8  残 1,036  遅延 1件
                        [CSVエクスポート（入荷予定）] [+ 入荷予定を追加]
─────────────────────────────────────────────────────
入荷予定日 商品名 SKU ロットNo 賞味期限 入荷先 仕入先 予定 入荷済 残 状態 操作
```

一覧は**入荷予定日の早い順**に並びます（同じ日なら登録した順）。

### 絞り込み

| 条件 | 対象 |
|------|------|
| キーワード | 商品名・SKU・ロットNo・仕入先の部分一致 |
| 予定日の範囲 | 入荷予定日（開始日・終了日とも、その日を含む） |
| 状態 | 未入荷 / 一部入荷 / 入荷済 / キャンセル |
| 倉庫 | 入荷先倉庫 |

### 集計（絞り込み後の合計）

| 項目 | 内容 |
|------|------|
| 件数 | 表示中の予定の件数（絞り込み中は「/ 全N件」も表示） |
| 予定 | 予定数量の合計。**キャンセルした予定は含めません** |
| 入荷済 | すでに入荷した数量の合計 |
| 残 | まだ届いていない数量の合計 |
| 遅延 | 入荷予定日を過ぎても残数がある予定の件数（0件なら非表示） |

---

## 2. 状態

状態は入力するものではなく、**予定数量と入荷済数量から自動で決まります**（キャンセルだけは操作で決まります）。

| 状態 | 条件 | できること |
|------|------|-----------|
| 未入荷 | 入荷済が0 | 入荷・編集・取消・削除 |
| 一部入荷 | 入荷済が1以上、予定数量未満 | 入荷・編集・取消・削除 |
| 入荷済 | 入荷済が予定数量以上 | 編集・削除（入荷と取消はできません） |
| キャンセル | 「取消」した予定 | 削除のみ（入荷・編集はできません） |

入荷予定日を過ぎても残数がある予定には、日付の横に赤い **遅延**バッジが付き、行が黄色くなります。

---

## 3. 入荷予定を登録する

「+ 入荷予定を追加」を押すと入力フォームが開きます。入力欄は2列に並び（狭い画面では1列）、
「キャンセル／保存」ボタンはフォームの下に固定されているので、画面が低くても押せます。

| 入力欄 | 必須 | 内容 |
|--------|------|------|
| 商品 | ○ | 登録済みの商品から選びます（商品が0件のときは登録できません） |
| 入荷予定日 | ○ | 届く予定の日 |
| 予定数量 | ○ | 1以上 |
| 入荷先倉庫 | ○ | 届いた在庫を置く倉庫 |
| 賞味期限 | | 入力するとロットNoを自動生成します |
| ロットNo | ○ | 半角数字8桁 |
| 仕入先 | | 自由入力。入出庫帳票の備考にも残ります |
| 備考 | | 自由入力 |

ここで入れた**ロットNo・賞味期限・倉庫は「予定値」**で、入荷のときに実際に届いたものへ直せます。

### 編集

「編集」で同じフォームが開きます。**入荷済数量は編集できません**（入荷の記録だからです）。
一部入荷のあとで予定数量を入荷済数量より小さくすると、その予定は入荷済になります。

---

## 4. 入荷する（在庫にする）

行の「入荷」を押すと入荷フォームが開きます。予定の内容が初期値として入っています。
こちらも入力欄は2列で、「キャンセル／入荷する」ボタンは下に固定されています。

| 入力欄 | 初期値 | 備考 |
|--------|--------|------|
| 入荷数量 | 残数 | **1以上・残数以下**。残数より多くは入荷できません |
| 入荷先倉庫 | 予定の倉庫 | 実際に置いた倉庫へ変更可 |
| 賞味期限 | 予定の賞味期限 | 実物に合わせて変更可 |
| ロットNo | 予定のロットNo | 半角数字8桁 |
| 備考 | 空欄 | 空欄なら帳票に `入荷予定（仕入先）` と記録されます |

フォームの下に「入荷後の在庫」が表示され、**確定前に結果を確認できます**。

```
新しいロット 20260818（販売倉庫）を作成します：12
入荷後の残数：0（この予定は入荷済になります）
```

### 在庫の増え方

- **ロットNo・入荷先倉庫・賞味期限がすべて同じロットが既にある場合**は、そのロットの在庫数に加算します。
- どれかが違う場合は、**新しいロットを作ります**。

分割で届いた（例：20個の予定のうち8個だけ先に到着）場合も、同じ内容で入荷すれば同じロットにまとまります。

### 記録されること

入荷1回につき、入出庫帳票に **入荷** が1件記録されます（数量・入荷先倉庫・備考つき）。
残数が0になると、その予定は自動的に「入荷済」になります。

---

## 5. 取消と削除

似ていますが意味が違います。

| 操作 | 何が起きるか | 使う場面 |
|------|--------------|----------|
| **取消** | 状態が「キャンセル」になり、残数が0になる。予定は一覧に残る | 発注をやめた・欠品になった |
| **削除** | 予定そのものが消える。記録は残らない | 間違えて登録した |

どちらも確認ダイアログが出ます。**すでに入荷した分の在庫と帳票は、取消・削除しても消えません。**
（入荷を取り消したいときは、在庫一覧のロット行から出庫・調整してください。）

---

## 6. CSVエクスポート（入荷予定）

**絞り込み後**の一覧をそのままCSVに書き出します。ファイル名は `入荷予定_YYYY-MM-DD.csv`。

```
入荷予定日,商品名,SKU,ロットNo,賞味期限,入荷先倉庫,仕入先,予定数量,入荷済,残数,状態,備考
2026-08-16,牛乳,ML-001,20260826,2026-08-26,販売倉庫,山田乳業,24,0,24,未入荷,定期便
```

---

## 7. 注意点

- **商品を削除すると、その商品の入荷予定も一緒に消えます。**（入荷済みの在庫と帳票は残ります。）
- **入荷待ちの予定が入荷先にしている倉庫は削除できません。**先に予定を取り消すか、入荷先を変えてください。
- 予定より多く届いた（過入荷）場合、その予定では残数までしか入荷できません。
  超えた分は在庫一覧のロット行から「入庫」するか、予定数量を増やしてから入荷してください。
- 入荷予定はダッシュボードの集計には含まれません（ダッシュボードは手元にある在庫だけを見る画面です）。
