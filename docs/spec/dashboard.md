# ダッシュボードタブ

在庫全体の状況と「いま手を打つべきもの」を1画面で確認する画面です。
在庫を変更する操作は基本的に在庫一覧タブで行いますが、**期限アラートからの一括廃棄だけはこの画面で実行できます**
（期限切れの処分は、見つけた場所でそのまま片付けられるほうが早いためです）。

朝いちばんに開いて、要発注と期限アラートを確認し、期限切れをまとめて処分する使い方を想定しています。

> このタブでは、他タブに出ている共通のアラートバナーとサマリカードは非表示になります（同じ内容をより詳しく出すため）。
> 開発者向けの補足は [../dashboard-feature.md](../dashboard-feature.md) にもあります。

商品が1件も登録されていないときは「商品が登録されていません。在庫一覧から商品を追加すると集計が表示されます。」と表示されます。

## 1. サマリカード（上部6枚）

| カード | 内容 | 小さい文字（サブ表示） |
|--------|------|------------------------|
| 在庫金額（原価） | 全ロットの `在庫数 × 原価` の合計（原価はロットごとの原価。未入力なら商品の現在原価） | 販売定価で計算した金額 |
| 在庫数 | 全ロットの在庫数の合計 | 商品数 / ロット数 |
| 要発注 | 合計在庫が発注点**以下**の商品数 | うち欠品（在庫0）の商品数 |
| 期限切れロット | 賞味期限が今日より前のロット数 | — |
| 期限間近ロット | 選んだ表示範囲以内に期限を迎えるロット数 | 表示範囲（7/14/30日） |
| 今月の廃棄ロス | 今月の廃棄の合計金額（原価ベース） | 廃棄の件数 / 数量 |

- 「欠品」は「要発注」の**内数**です（在庫0は発注点以下でもあるため、両方に数えられます）。
- 期限切れ・期限間近は、**在庫が残っているロットだけ**を数えます（在庫0のロットは無視）。
  画面上部の共通サマリは在庫0のロットも数えるため、数字が食い違うことがあります。
- 「期限間近ロット」の数は、下の「期限アラート」で選んだ表示範囲に連動します。

## 2. 要発注リスト（在庫数 ≦ 発注点）

合計在庫が発注点以下の商品を、**不足数の多い順**（同数なら商品名順）に並べます。

| 列 | 意味 |
|----|------|
| 商品名 / SKU / カテゴリ | 商品の識別情報 |
| 在庫数 | 合計在庫。0のときは「欠品」バッジ |
| 発注点 | その商品の最低在庫数 |
| 不足数 | `発注点 − 在庫数`。発注点ちょうどなら「—」 |
| 発注見込金額 | `不足数 × 原価`。発注に必要なおおよその金額 |

- 見出し右に、リスト全体の発注見込金額の合計が表示されます。
- 在庫0の行は赤、それ以外は薄い赤で強調されます。
- **発注点ちょうどの商品も表示されます**（不足数0）。「そろそろ発注」の予告として並びます。
- 「CSVエクスポート（要発注リスト）」で `要発注リスト_YYYY-MM-DD.csv` を出力できます。発注依頼の下書きに使えます。

```
商品名,SKU,カテゴリ,在庫数,発注点,不足数,発注見込金額
値札ラベル(赤),LB-R01,ラベル,0,100,100,200
食パン,BR-001,パン,3,5,2,180
```

## 3. 期限アラート

期限切れ＋表示範囲以内に期限を迎えるロットを、**期限の早い順**に並べます。

| 列 | 意味 |
|----|------|
| （チェックボックス） | 廃棄する行を選ぶ。見出しのチェックで表示中の全行を選択 |
| 商品名 / SKU / ロットNo | 対象ロットの識別情報 |
| 賞味期限 | 日付 |
| 残日数 | 期限切れは「N日経過」、当日は「今日まで」、それ以外は「N日後」 |
| 倉庫 | 保管倉庫 |
| 在庫数 | そのロットの在庫数 |
| 在庫金額（原価） | `在庫数 × そのロットの原価`（未入力なら商品の現在原価）。放置すると廃棄損になりうる金額 |

- **表示範囲は 7日 / 14日 / 30日** から選べます。上のサマリカード「期限間近ロット」も連動します。
- 見出し右に、表示中のロットの在庫金額合計（＝リスクにさらされている金額）が出ます。
- 在庫0のロットと、賞味期限のないロットは対象外です。

### 選択したロットを廃棄する

期限切れの在庫は、この画面から**まとめて処分**できます。

1. 各行のチェックボックスで対象を選ぶ（「期限切れを選択（N件）」を押すと、**期限切れの行だけ**が一括で選ばれます）
2. 「選択したロットを廃棄（N件）」を押す
3. 確認画面で、廃棄するロット数・数量・**廃棄ロス金額**を確認して「廃棄する」

確認画面の例：

```
3ロット（14個・¥1,820）を廃棄します。
（期限切れ 2件 / 期限内 1件）

※ まだ期限の来ていないロットが含まれています。

廃棄したロットは在庫一覧から取り除かれ、入出庫帳票に「廃棄」として記録されます。
この操作は取り消せません。よろしいですか？
```

- 廃棄は**ロットの全量**が対象です（一部だけ廃棄したいときは、在庫一覧タブのロット行の「出庫」で区分に「廃棄」を選んでください）。
- **廃棄したロットは在庫一覧から取り除かれます。**在庫0のロットを残すと画面上部の「期限切れロットあり」バナーが
  消えないためで、何をいくつ廃棄したかは入出庫帳票に残ります。
- 入出庫帳票には**ロット1件につき1行**、区分「廃棄」・備考「一括廃棄」で記録されます。
- 期限内のロットも選べます（当日中に処分すると決めた分など）。その場合は確認画面に注意書きが出ます。
- **表示範囲を狭めて見えなくなった行は廃棄されません。**ボタンの件数は、いま画面に出ている行のうち選択済みのものだけを数えます。

## 4. 廃棄ロス（商品別）

入出庫帳票に記録された「廃棄」を、商品ごとに集計して**ロス金額の大きい順**に並べます。
どの商品で捨てが多いのかを見て、発注量や陳列の見直しに使うための表です。

| 列 | 意味 |
|----|------|
| 商品名 / SKU | 商品の識別情報 |
| 廃棄件数 | 帳票に記録された廃棄の行数 |
| 廃棄数量 | 廃棄した数量の合計 |
| 廃棄金額（原価） | `廃棄数量 × 原価` |

- **集計期間は 今月 / 今年 / 全期間** から選べます（初期表示は今月）。サマリカードの「今月の廃棄ロス」は常に今月です。
- 一括廃棄だけでなく、**在庫一覧のロット行の「出庫」やFEFO出庫で区分に「廃棄」を選んだ分も含まれます**。
- **ダッシュボードの「選択したロットを廃棄」（一括廃棄）で捨てた分は、そのロット自体の原価で正確に計算されます**
  （ロットに原価が入っていなければ廃棄した時点の商品原価）。一方、在庫一覧のロット行「出庫」やFEFO出庫で
  区分を「廃棄」にした分は、いつ捨てても**商品マスタの現在の原価**を掛けた概算のままです（原価を変更すると
  過去の廃棄金額も新しい原価で計算し直されます）。削除された商品の廃棄は原価が分からないため、数量だけを
  数えて金額は0になります。
- 「CSVエクスポート（廃棄ロス）」で `廃棄ロス_YYYY-MM-DD.csv` を出力できます。

```
商品名,SKU,廃棄件数,廃棄数量,廃棄金額（原価）
牛乳,ML-001,2,5,650
食パン,BR-001,1,3,270
```

## 5. 倉庫別在庫 / カテゴリ別在庫

画面下部に2つの表が並びます。

| 列 | 意味 |
|----|------|
| 倉庫 / カテゴリ | 集計の単位 |
| 商品数 | その倉庫にロットがある商品数 / そのカテゴリの商品数 |
| 在庫数 | 在庫数の合計 |
| 在庫金額（原価） | `在庫数 × ロットの原価` の合計（未入力のロットは商品の現在原価） |
| 構成比 | 在庫金額（原価）の全体に占める割合をバーで表示 |

- 在庫のない倉庫・商品のないカテゴリも、0件の行として残ります（登録されているものは必ず並びます）。
- 1つの商品が複数の倉庫にロットを持つ場合、**倉庫別の「商品数」はそれぞれの倉庫で1件ずつ数えられます**。
  そのため倉庫別の商品数を足し合わせても、総商品数とは一致しません。

### 開発者向けメモ

- 画面：`src/DashboardView.tsx`（集計ロジックは持たず表示と選択状態のみ）
- 集計：`src/useInventory.ts` の `dashboardTotals` / `lowStockRows` / `expiringLotRows` / `warehouseSummaries` / `categorySummaries` / `lowStockCsv`
- 廃棄：プレビューは純粋関数 `planDisposal`、実行は `disposeLots`（`App.tsx` 経由で `onDispose` として渡す）。
  実績の集計は `disposalTransactions` / `disposalRows` / `disposalTotals` / `disposalCsv`、期間は `disposalPeriodStart`
- しきい値の定数：`EXPIRY_SOON_DAYS`（7日）、`DASHBOARD_EXPIRY_OPTIONS`（`[7, 14, 30]`）、`DISPOSAL_PERIODS`（今月/今年/全期間）
