# ダッシュボードタブ

在庫全体の状況と「いま手を打つべきもの」を1画面で確認するための、**見るだけの画面**です。
この画面から在庫を動かすことはできません（変更操作は在庫一覧タブで行います）。

朝いちばんに開いて、要発注と期限アラートを確認する使い方を想定しています。

> このタブでは、他タブに出ている共通のアラートバナーとサマリカードは非表示になります（同じ内容をより詳しく出すため）。
> 開発者向けの補足は [../dashboard-feature.md](../dashboard-feature.md) にもあります。

商品が1件も登録されていないときは「商品が登録されていません。在庫一覧から商品を追加すると集計が表示されます。」と表示されます。

---

## 1. サマリカード（上部5枚）

| カード | 内容 | 小さい文字（サブ表示） |
|--------|------|------------------------|
| 在庫金額（原価） | 全ロットの `在庫数 × 原価` の合計 | 販売定価で計算した金額 |
| 在庫数 | 全ロットの在庫数の合計 | 商品数 / ロット数 |
| 要発注 | 合計在庫が発注点**以下**の商品数 | うち欠品（在庫0）の商品数 |
| 期限切れロット | 賞味期限が今日より前のロット数 | — |
| 期限間近ロット | 選んだ表示範囲以内に期限を迎えるロット数 | 表示範囲（7/14/30日） |

- 「欠品」は「要発注」の**内数**です（在庫0は発注点以下でもあるため、両方に数えられます）。
- 期限切れ・期限間近は、**在庫が残っているロットだけ**を数えます（在庫0のロットは無視）。
  画面上部の共通サマリは在庫0のロットも数えるため、数字が食い違うことがあります。
- 「期限間近ロット」の数は、下の「期限アラート」で選んだ表示範囲に連動します。

---

## 2. 要発注リスト（在庫数 ≦ 発注点）

合計在庫が発注点以下の商品を、**不足数の多い順**（同数なら商品名順）に並べます。

| 列 | 意味 |
|----|------|
| 商品名 / SKU / カテゴリ | 商品の識別情報 |
| 在庫数 | 合計在庫。0のときは「欠品」バッジ |
| 発注点 | その商品の最低在庫数 |
| 不足数 | `発注点 − 在庫数`。発注点ちょうどなら「—」 |
| 発注見込金額 | `不足数 × 原価`。発注に必要なおおよその金額 |

- 見出し右に、リスト全体の発注見込金額の合計が表示されます。
- 在庫0の行は赤、それ以外は薄い赤で強調されます。
- **発注点ちょうどの商品も表示されます**（不足数0）。「そろそろ発注」の予告として並びます。
- 「CSVエクスポート（要発注リスト）」で `要発注リスト_YYYY-MM-DD.csv` を出力できます。発注依頼の下書きに使えます。

```
商品名,SKU,カテゴリ,在庫数,発注点,不足数,発注見込金額
値札ラベル(赤),LB-R01,ラベル,0,100,100,200
食パン,BR-001,パン,3,5,2,180
```

## 3. 期限アラート

期限切れ＋表示範囲以内に期限を迎えるロットを、**期限の早い順**に並べます。

| 列 | 意味 |
|----|------|
| 商品名 / SKU / ロットNo | 対象ロットの識別情報 |
| 賞味期限 | 日付 |
| 残日数 | 期限切れは「N日経過」、当日は「今日まで」、それ以外は「N日後」 |
| 倉庫 | 保管倉庫 |
| 在庫数 | そのロットの在庫数 |
| 在庫金額（原価） | `在庫数 × 原価`。放置すると廃棄損になりうる金額 |

- **表示範囲は 7日 / 14日 / 30日** から選べます。上のサマリカード「期限間近ロット」も連動します。
- 見出し右に、表示中のロットの在庫金額合計（＝リスクにさらされている金額）が出ます。
- 在庫0のロットと、賞味期限のないロットは対象外です。

---

## 4. 倉庫別在庫 / カテゴリ別在庫

画面下部に2つの表が並びます。

| 列 | 意味 |
|----|------|
| 倉庫 / カテゴリ | 集計の単位 |
| 商品数 | その倉庫にロットがある商品数 / そのカテゴリの商品数 |
| 在庫数 | 在庫数の合計 |
| 在庫金額（原価） | `在庫数 × 原価` の合計 |
| 構成比 | 在庫金額（原価）の全体に占める割合をバーで表示 |

- 在庫のない倉庫・商品のないカテゴリも、0件の行として残ります（登録されているものは必ず並びます）。
- 1つの商品が複数の倉庫にロットを持つ場合、**倉庫別の「商品数」はそれぞれの倉庫で1件ずつ数えられます**。
  そのため倉庫別の商品数を足し合わせても、総商品数とは一致しません。
