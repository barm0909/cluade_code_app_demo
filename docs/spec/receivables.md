# 入金管理タブ

発行した **請求書に入金を充てて（消込）**、請求書ごとの残高と、得意先ごとの **売掛金残高** を管理する画面です。
タブは「納品書・請求書」の右隣にあります。

- 対象になるのは「納品書・請求書」タブで発行した **請求書** だけです（納品書は請求ではないので含めません）
- 請求書の入金状況（未入金・一部入金・入金済）や残高・期限超過は、登録した入金から **毎回計算** します。手で書き換える欄はありません
- **この画面で在庫が動くことはありません。** 入金を登録しても削除しても、入出庫帳票には何も記録されません

---

## 1. 画面の構成

```
[売掛金残高 ¥3,740] [請求残高 ¥3,300 / 未回収3枚] [期限超過 ¥1,100 / 1枚] [未請求売上 ¥440] [今月の入金 ¥0 / 未消込 ¥0]

入金・売掛金                                                     [+ 入金を登録]
[請求書別] [得意先別] [入金履歴]
──────────────────────────────────────────────────────────────────────
（選んだ表示の一覧）
```

### サマリカード

| カード | 中身 |
|--------|------|
| 売掛金残高 | 請求残高 ＋ 未請求売上 − 未消込入金。得意先から回収するべき額の合計 |
| 請求残高 | 発行した請求書の残高（請求額 − 消込済みの額）の合計と、残高のある請求書の枚数 |
| 期限超過 | お支払期限を過ぎても残高がある請求書の残高の合計と枚数（赤字） |
| 未請求売上（税込） | 得意先つきの売上のうち、まだどの請求書にも載せていないもの（返品は差し引き） |
| 今月の入金 | 今月の入金日の入金額の合計（振込手数料は含めない）と、どの請求書にも充てていない入金の合計 |

> 未請求売上の消費税は売上管理と同じく **売上1件ごとに端数処理** した額です。請求書にすると税率ごとに1回の
> 端数処理になるため、請求書の金額とは数円ずれることがあります（[sales-document.md](sales-document.md)）。

---

## 2. 請求書別

発行した請求書を1枚1行で並べます。並びは **お支払期限の早い順**（期限のない請求書は最後）です。

| 列 | 中身 |
|----|------|
| 請求書番号・得意先・発行日 | 請求書を発行した時点の内容 |
| お支払期限 | 期限を過ぎて残高があると「○日超過」の赤い印がつき、行全体が強調されます |
| 請求額（税込） | 請求書の合計金額 |
| 入金済 | この請求書に充てた入金（入金額 ＋ 振込手数料）の合計と、最後に充てた入金日 |
| 残高 | 請求額 − 入金済 |
| 状況 | **未入金**（入金なし）／ **一部入金** ／ **入金済**（残高0）。請求額が0以下の請求書（返品だけの請求書など）は回収するものがないので入金済になります |
| 操作 | 「入金登録」：この請求書を選んだ状態で入金登録を開きます（入金済の行では押せません） |

### 絞り込み

| 条件 | 対象 |
|------|------|
| キーワード | 請求書番号・得意先名の部分一致 |
| 得意先 | 得意先マスタの得意先 |
| 入金状況 | **未回収（未入金・一部入金）**（初期値）／ 期限超過 ／ 未入金 ／ 一部入金 ／ 入金済 ／ すべて |

画面を開いたときは「未回収」だけを表示しています。全額入金された請求書は一覧から消えるので、
確認したいときは入金状況を「入金済」か「すべて」にしてください。「条件クリア」は初期値（未回収）に戻します。

---

## 3. 得意先別

得意先ごとに、回収するべき額を並べます。並びは **売掛金残高の多い順** です。
残高・未請求売上・未消込入金のどれもない得意先は出ません。

| 列 | 中身 |
|----|------|
| 請求残高 | その得意先の請求書の残高の合計（下に残高のある請求書の枚数） |
| うち期限超過 | そのうちお支払期限を過ぎている額 |
| 未請求売上（税込） | まだ請求書に載せていない売上 |
| 未消込入金 | どの請求書にも充てていない入金（前受・過入金） |
| 売掛金残高 | 請求残高 ＋ 未請求売上 − 未消込入金 |
| 最終入金日 | その得意先の入金のうち最新の入金日 |
| 操作 | 「入金登録」：この得意先を選んだ状態で入金登録を開きます |

得意先を指定せずに登録した売上は、請求先がないのでどの得意先にも入りません。

---

## 4. 入金履歴

登録した入金を、**1回の入金（振込1回）につき1行** で並べます。並びは入金日の新しい順です。

| 列 | 中身 |
|----|------|
| 入金日・得意先・方法 | 登録した内容 |
| 入金額 | 実際に受け取った額 |
| 手数料 | 振込手数料（得意先が差し引いて振り込んだ額） |
| 消込先 | 充てた請求書と、その請求書に充てた額（入金額 ＋ 手数料）。充てきれなかった分は「未消込 ¥○」 |
| 操作 | 「削除」：確認のうえ、その入金をまとめて削除します。充てていた請求書の残高は元に戻ります |

絞り込みはキーワード（得意先名・請求書番号・備考）、得意先、入金日の期間（両端を含む）です。

---

## 5. 入金を登録する

「+ 入金を登録」、または請求書別・得意先別の行の「入金登録」から開きます。

| 入力欄 | 内容 | 初期値 |
|--------|------|--------|
| 得意先 | 入金した得意先。取引停止の得意先も、残高があれば選べます | 開いた行の得意先（「+ 入金を登録」からは未選択） |
| 入金日 | 入金のあった日 | 今日 |
| 入金額 | 実際に受け取った額（1円以上の整数） | 空欄 |
| 振込手数料 | 得意先が差し引いて振り込んだ額（0円以上の整数）。入金額と合わせて請求書の消込に充てます | 0 |
| 入金方法 | 振込 ／ 現金 ／ 手形 ／ 相殺 ／ その他 | 振込 |
| 備考 | 任意（例: 11月分） | 空欄 |

得意先を選ぶと、その得意先の **残高のある請求書** がお支払期限の早い順に並びます。

- チェックした請求書に、**お支払期限の早いものから順に**、残高いっぱいまで充てます
- 「今回の消込」「消込後の残高」の列で、どの請求書にいくら充たるかを登録前に確認できます
- 請求書の行の「入金登録」から開いたときは、その請求書だけがチェックされています。「+ 入金を登録」や
  得意先別から開いたときは、残高のある請求書がすべてチェックされています
- 「選んだ請求書の残高 ¥○ を入金額に入れる」を押すと、チェックした請求書の残高の合計から振込手数料を引いた額が入金額に入ります
- **充てきれなかった額は「未消込」** として残ります（前受金や払いすぎ）。登録前に「未消込 ¥○（前受・過入金として残します）」と表示されます
- 振込手数料は、先に充てた請求書から順に割り当てます

「登録する」を押すと記録され、一覧の残高・状況がすぐに変わります。

### 例

請求書A（期限 7/31・残高 ¥1,100）と請求書B（期限 8/31・残高 ¥2,200）がある得意先から、
手数料 ¥440 を差し引いた ¥2,860 が振り込まれた場合：

| 請求書 | 今回の消込 | 内訳 | 消込後の残高 |
|--------|-----------|------|-------------|
| A | ¥1,100 | 入金 ¥660 ＋ 手数料 ¥440 | ¥0（入金済） |
| B | ¥2,200 | 入金 ¥2,200 | ¥0（入金済） |

---

## 6. 注意点

- **入金を充てた請求書は取り消せません。** 「納品書・請求書」タブの「取消」ボタンが押せなくなります。
  請求書を出し直したいときは、先にこの画面の入金履歴から入金を削除してください
- **入金の記録がある得意先は、得意先マスタから削除できません**（未消込の入金だけでも同じ）。取引停止にしてください
- 入金の金額や消込先は編集できません。間違えたときは入金履歴から削除して、登録し直してください
- 未消込の入金をあとから請求書に充てる操作はありません。新しい請求書に充てたいときは、その入金を削除して登録し直してください
- 1回の入金で別々の得意先の請求書をまとめて消し込むことはできません（得意先ごとに登録してください）
- ヘッダーの「リセット」を押すと、請求書と一緒に入金の記録もすべて消えます

## 7. CSVエクスポート

表示ごとにボタンがあり、どれも **絞り込み後** の内容を出力します。

| 表示 | 出力ファイル | 中身（1行） |
|------|--------------|-------------|
| 請求書別 | `請求残高_YYYY-MM-DD.csv` | 請求書1枚（請求書番号・得意先・発行日・お支払期限・請求額・入金済額・残高・入金状況・期限超過日数・最終入金日） |
| 得意先別 | `売掛金残高_YYYY-MM-DD.csv` | 得意先1件（請求残高・うち期限超過・未回収の請求書・未請求売上・未消込入金・売掛金残高・最終入金日） |
| 入金履歴 | `入金履歴_YYYY-MM-DD.csv` | 入金を充てた請求書1枚分（入金日・得意先・入金方法・消込先請求書・入金額・振込手数料・消込額・備考）。充てきれなかった分は消込先「未消込」の行 |

---

## 8. ダッシュボードとの関係

ダッシュボードの「期限超過の売掛金」カードと「未回収アラート」に、お支払期限を過ぎて残高のある請求書が
超過日数の長い順に出ます（[dashboard.md](dashboard.md)）。入金はこの画面で登録します。
