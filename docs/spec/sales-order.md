# 受注タブ

得意先から受けた注文のうち、**まだ出荷していないもの（出荷予定）**を登録しておき、
出荷するときにその受注から在庫を引き落とす画面です。入荷予定タブの「販売側」にあたります。

「いつ・誰に・何を・いくつ出す予定か」を見える化し、**今の在庫で足りるか（引当）**をその場で確認できます。
出荷するときは受注の内容（得意先・単価）がそのまま使われるので、売上登録で毎回入力し直す必要がありません。

> **受注は在庫ではありません。** 受注を登録しただけでは在庫数は1つも減りません。
> 在庫が減るのは「出荷」ボタンを押したときだけです（そのとき入出庫帳票に **売上出庫** が記録され、売上管理タブに並びます）。

---

## 1. 画面の構成

```
[検索] [出荷予定日 〜 出荷予定日] [状態▼] [得意先▼] [条件クリア]
─────────────────────────────────────────────────────
3件  受注 25  出荷済 0  残 25（¥4,770）  在庫不足 1件  遅延 1件
                        [CSVエクスポート（受注一覧）] [+ 受注を登録]
─────────────────────────────────────────────────────
出荷予定日 得意先 商品名 SKU 出荷元 受注単価 受注 出荷済 残 引当 状態 操作
```

一覧は**出荷予定日の早い順**に並びます（同じ日なら登録した順）。この並び順は、引当で在庫を割り当てる順番でもあります。

### 絞り込み

| 条件 | 対象 |
|------|------|
| キーワード | 商品名・SKU・得意先名の部分一致 |
| 出荷予定日の範囲 | 出荷予定日（開始日・終了日とも、その日を含む） |
| 状態 | 未出荷 / 一部出荷 / 出荷済 / キャンセル |
| 得意先 | 得意先マスタに登録された得意先 |

### 集計（絞り込み後の合計）

| 項目 | 内容 |
|------|------|
| 件数 | 表示中の受注の件数（絞り込み中は「/ 全N件」も表示） |
| 受注 | 受注数量の合計。**キャンセルした受注は含めません** |
| 出荷済 | すでに出荷した数量の合計 |
| 残 | まだ出荷していない数量（受注残）の合計と、その金額（税抜） |
| 在庫不足 | 引当で在庫が足りない受注の件数（0件なら非表示） |
| 遅延 | 出荷予定日を過ぎても受注残がある受注の件数（0件なら非表示） |

---

## 2. 状態

状態は入力するものではなく、**受注数量と出荷済数量から自動で決まります**（キャンセルだけは操作で決まります）。

| 状態 | 条件 | できること |
|------|------|-----------|
| 未出荷 | 出荷済が0 | 出荷・編集・取消・削除 |
| 一部出荷 | 出荷済が1以上、受注数量未満 | 出荷・編集・取消・削除 |
| 出荷済 | 出荷済が受注数量以上 | 編集・削除（出荷と取消はできません） |
| キャンセル | 「取消」した受注 | 削除のみ（出荷・編集はできません） |

出荷予定日を過ぎても受注残がある受注には、日付の横に赤い **遅延**バッジが付き、行が黄色くなります。
在庫不足の受注は行が薄い青になります（在庫一覧の在庫不足の行と同じ色。遅延より優先）。

---

## 3. 引当（在庫が足りるか）

「引当」列は、**今ある在庫でその受注を出荷できるか**の見込みです。

- 受注残のある受注を**出荷予定日の早い順**（同じ日なら登録順）に並べ、
  在庫を**賞味期限の近いロットから**（FEFO）順に割り当てていきます。
- 先の受注に割り当てた在庫は、後の受注には数えません（同じ在庫を二重に当てにしません）。
- 足りれば **引当可**、足りなければ **不足 N**（足りない数量）と表示します。
- **期限切れのロットは数えません**（出荷の既定と同じ）。
- 出荷元倉庫を指定した受注は、**その倉庫の在庫だけ**を見ます。

```
食パンの在庫：3
  受注A（10/8 出荷予定）  5 → 引当 3・不足 2
  受注B（10/9 出荷予定）  4 → 引当 0・不足 4
```

> **引当は「取り置き」ではありません。** 在庫に予約の印を付けるのではなく、画面を表示するたびに計算し直す見込みです。
> そのため、売上登録・FEFO出庫・廃棄などで在庫が減れば、引当結果もすぐに変わります。
> また、出荷するときは他の受注の分として見込んでいた在庫も引けます（どの受注から出すかは出荷する人が決めます）。

絞り込みで一部の受注を隠しても、引当は**すべての受注**で計算します（隠れた受注が押さえている在庫は変わらないため）。

---

## 4. 受注を登録する

「+ 受注を登録」を押すと入力フォームが開きます。

| 入力欄 | 必須 | 内容 |
|--------|------|------|
| 得意先 | ○ | **得意先マスタから選択**（取引停止の得意先は選べません） |
| 商品 | ○ | 登録済みの**販売品**から選びます（**資材は受注できません**） |
| 出荷予定日 | ○ | 出荷する予定の日 |
| 受注数量 | ○ | 1以上 |
| 受注単価 | | **税抜**の円。初期値は商品の販売定価（手で変えなければ商品を選び直すたびに追従）。**0は「未入力」**扱い |
| 出荷元倉庫 | | 未指定（全倉庫）か、特定の倉庫 |
| 備考 | | 自由入力 |

得意先・商品が1件も登録されていないときは、その旨の案内が出て登録できません。
単価を入れると、受注金額（税抜）と税込の目安が表示されます
（実際の消費税は、出荷時に引き当てたロットごとに端数処理されるため、数円ずれることがあります）。

### 編集

「編集」で同じフォームが開きます。**出荷済数量は編集できません**（出荷の記録だからです）。
一部出荷のあとで受注数量を出荷済数量以下にすると、その受注は出荷済になります。

---

## 5. 出荷する

行の「出荷」を押すと出荷フォームが開きます。

| 入力欄 | 初期値 | 備考 |
|--------|--------|------|
| 出荷数量 | 受注残 | **1以上・受注残以下**。受注残より多くは出荷できません |
| 期限切れロットも引当対象にする | オフ | オンにすると期限切れのロットからも出荷します |
| 備考 | 空欄 | 空欄なら帳票に `受注出荷（得意先名）` と記録されます |

フォームには **引当プレビュー**（どのロットから何個出るか・原価）と、
**売上金額（税抜）・消費税・税込・原価・粗利**が表示され、確定前に結果を確認できます。
このプレビューは実際の出荷とまったく同じ計算なので、表示どおりのロットから出ます。

- 在庫が足りないときは不足数が表示され、「出荷する」ボタンは押せません。
  **出荷数量を減らせば、ある分だけ先に出荷（分割出荷）できます。**
- 受注単価が未入力（0）の受注は、販売定価で概算した金額が表示されます。

### 記録されること

出荷1回につき、引き当てたロットの数だけ入出庫帳票に **売上出庫** が記録されます。
受注単価・得意先・そのロットの原価・商品の税率も一緒に記録されるので、**売上管理タブにそのまま並びます**。
受注残が0になると、その受注は自動的に「出荷済」になります。

---

## 6. 取消と削除

| 操作 | 何が起きるか | 使う場面 |
|------|--------------|----------|
| **取消** | 状態が「キャンセル」になり、受注残が0になる。受注は一覧に残る | 注文が取り消された・欠品で断った |
| **削除** | 受注そのものが消える。記録は残らない | 間違えて登録した |

どちらも確認ダイアログが出ます。**すでに出荷した分の売上と帳票は、取消・削除しても消えません。**

---

## 7. CSVエクスポート（受注一覧）

**絞り込み後**の一覧をそのままCSVに書き出します。ファイル名は `受注一覧_YYYY-MM-DD.csv`。

```
出荷予定日,得意先,商品名,SKU,出荷元倉庫,受注単価(税抜),受注数量,出荷済,受注残,引当可能,在庫不足,受注残金額(税抜),状態,概算,備考
2026-10-08,みどりストア,牛乳,ML-001,全倉庫,190,12,0,12,12,0,2280,未出荷,,定期配送
```

受注単価が未入力の行は、販売定価を単価に使い「概算」列に `概算` と出ます。

---

## 8. 注意点

- **商品を削除すると、その商品の受注も一緒に消えます。**（出荷済みの売上と帳票は残ります。）
- **受注のある得意先は削除できません**（取消・出荷済の受注も数えます）。取引が終わった得意先は「取引停止」にしてください。
- **出荷待ちの受注が出荷元にしている倉庫は削除できません。**先に受注を取り消すか、出荷元を変えてください。
- 受注はダッシュボードの集計・発注提案には含まれません（発注提案は手元の在庫と入荷予定だけを見ます）。
  受注に対して在庫が足りないときは、この画面の「在庫不足」を見て入荷予定を登録してください。
- 出荷は売上出庫と同じ扱いなので、出荷を取り消したいときは在庫一覧のロット行から「入庫（調整入庫）」で在庫を戻してください
  （受注の出荷済数量は戻りません。必要なら受注を編集して受注数量を増やしてください）。
