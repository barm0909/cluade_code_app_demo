# 売上管理タブ

**実際に売れた金額**を記録し、売上高・消費税・原価・粗利を確認するための画面です。
金額は**税抜**で入力・記録し、消費税と税込金額は商品ごとの税率（8% 軽減税率 / 10% 標準税率）から計算します。

出庫そのものは在庫一覧タブでもできますが、この画面では「いくらで・誰に売ったか」まで入力して
記録に残せます。そして残った記録を、明細・商品別・得意先別・日別で見比べられます。

「売上を登録」すると在庫が減り、入出庫帳票に**売上出庫**として記録されます
（売上の登録だけがこの画面で在庫を動かす操作です）。

上部のカードも一覧も、**すべて絞り込み後の範囲**で計算されます。

### 絞り込み

| 条件 | 対象 |
|------|------|
| キーワード | 商品名・SKU・得意先名の部分一致 |
| 期間 | 売上の日時（開始日・終了日とも、その日を含む） |
| 得意先 | 得意先マスタに登録された得意先。「得意先なし」だけを選ぶこともできます |
| 倉庫 | 出庫元の倉庫 |

### 4つの切り口

| ボタン | 内容 |
|--------|------|
| 明細 | 売上1件（＝引き当てたロット1つ）ごとの一覧。新しい順 |
| 商品別 | 商品ごとの合計。売上金額の多い順 |
| 得意先別 | 得意先ごとの合計。売上金額の多い順（「得意先なし」の売上も1行にまとまります） |
| 日別 | 日ごとの合計。**新しい日付順**（推移を見るため、金額順にはしません） |

集計の表には 件数・数量・売上金額（税抜）・消費税・税込金額・原価・粗利・粗利率・構成比（税抜の売上金額に占める割合）が並びます。

## 2. 売上を登録する

「+ 売上を登録」でダイアログが開きます。

| 入力 | 内容 |
|------|------|
| 商品 | 登録済みの商品から選びます（在庫数も表示されます） |
| 数量 | 1以上。引き当てられる在庫を超えると登録できません |
| 販売単価 | **税抜**で入力します。**初期値はその商品の販売定価**。値引きしたときはここを書き換えます。ラベルに商品の税率が表示されます |
| 得意先 | 任意。選ばなければ「得意先なし」として記録されます |
| 出庫元倉庫 | 「全倉庫」なら倉庫を問わず期限の近いロットから引き当てます |
| 備考 | 任意。空欄なら `売上登録` と記録されます |

どのロットから出るかは **FEFO（賞味期限の近いものから先に出す）** で自動的に決まります。
引当プレビューに、引き当てるロット・数量・そのロットの原価が出て、その下に
**売上金額（税抜）・消費税・税込金額・原価・粗利**が表示されます。ここに出る内容がそのまま記録されます。

- 「期限切れロットも引当対象にする」にチェックを入れない限り、期限切れの在庫は出庫されません
- 在庫が足りないときは不足数が表示され、「売上を登録」ボタンは押せません
- 登録すると、引き当てたロットの数だけ入出庫帳票に**売上出庫**が記録されます

### 在庫一覧タブから売った場合

在庫一覧タブの **FEFO出庫** と、ロット行の **出庫** でも、区分に「売上出庫」を選んだときだけ
**販売単価（税抜）**と**得意先**を入力できます。入力した内容はこの画面の集計に入ります。
どちらの画面でも、売上金額（税抜）・消費税・税込金額のプレビューが出ます。

## 3. 金額の決まり方

| 項目 | 計算 |
|------|------|
| 売上金額（税抜） | `売上単価（税抜） × 数量` |
| 消費税 | `売上金額（税抜） × 税率`。**明細1行ごとに1円未満を四捨五入** |
| 税込金額 | `売上金額（税抜） ＋ 消費税` |
| 原価 | `出庫した時点のそのロットの原価 × 数量` |
| 粗利 | `売上金額（税抜） − 原価`（消費税は預かっているだけのお金なので粗利に含めません） |
| 粗利率 | `粗利 ÷ 売上金額（税抜）`（売上金額が0なら0%） |

原価は**売ったときのロットの原価**です。売れたロットは在庫から減ってしまうため、
出庫したその瞬間の原価を記録として残しています（あとから商品の原価を変更しても、
過去の売上の粗利は変わりません）。

### 消費税の決まり方

- **税率は商品ごと**に商品マスタで設定します（8%（軽減）＝飲食料品 / 10%＝ラベル・資材など）。
- 税率も原価と同じく**売ったときの税率を記録に残します**。あとから商品の税率を変えても、過去の売上の消費税は変わりません。
- 消費税は**明細1行ごとに四捨五入**します。1回の売上登録でも、複数のロットから引き当てたときは
  ロットごとに1行ずつ記録されるので、その1行ごとに四捨五入されます（プレビューも同じ計算です）。
  合計の消費税は、各行の消費税の足し上げです。
- カードの**税率別の内訳**（8%対象 / 10%対象）は、請求書に書くときのように税率ごとの売上と消費税を分けて見るためのものです。
- 消費税の機能を追加する前の売上出庫には税率の記録がないため、**商品の現在の税率**で計算します
  （商品の税率が変わることはまずないため、「概算」の印はつけません）。

### 「概算」と表示される行

次の記録には売った単価が残っていないため、**商品の販売定価・現在の原価**で代用し、
「概算」と印をつけます。

- この機能を追加する前に記録された売上出庫
- 販売単価を **0（未入力）** のまま出庫した売上

**販売単価0は「0円で売った」ではなく「未入力」の扱い**です（入荷予定の仕入単価と同じ約束）。
無償提供を売上として記録したい場合は、1円以上の単価を入れるか、区分を「調整出庫」にして
売上に含めない運用にしてください。

## 5. 注意点

- **売上に数えるのは区分「売上出庫」だけです。** 調整出庫・廃棄・倉庫移動は売上になりません。
- **返品・取消の機能はありません。** 間違えて登録した売上は、在庫一覧タブで「入庫（調整入庫）」して
  在庫を戻してください（売上の記録自体は帳票に残ります）。
- **単価はすべて税抜です。** 税込の値段しか分からないときは、税抜に直して入力してください。
- 消費税の端数は明細1行ごとの四捨五入です。請求書を「請求書全体で1回だけ端数処理」する運用の場合、
  この画面の消費税合計と数円ずれることがあります。
- 在庫分析タブの「出庫金額」は原価ベースの別の数字です。売上高・粗利はこの画面で見てください。
- ヘッダーの「リセット」を押すと帳票も消えるため、売上の記録もなくなります。

  `salesProductSummaries` / `salesCustomerSummaries` / `salesDailySummaries` / `salesCsv` / `salesSummaryCsv`

  `StockTransaction.unitPrice` / `customerId` / `costUnitPrice` に入る
