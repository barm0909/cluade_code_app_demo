# 在庫一覧タブ（メイン作業画面）

日々の入庫・出庫・移動を行う、このシステムの中心となる画面です。
画面を開いた直後に表示されるのもこのタブです。

---

## 1. この画面でできること

| やりたいこと | 操作 |
|--------------|------|
| 商品を探す | 検索欄・カテゴリ／倉庫の絞り込み・列の並べ替え |
| 商品のロット（期限・倉庫ごとの在庫）を見る | 商品行をクリックして展開 |
| 入荷した在庫を登録する | ロットを追加する、または既存ロットに「入庫」 |
| 出荷・廃棄する | ロット行の「出庫」、または商品行の「FEFO出庫」 |
| 在庫を別の倉庫へ動かす | ロット行の「移動」 |
| 商品・ロットの内容を直す | それぞれの「編集」 |
| そのロットが入ってから出るまでを追う | ロット行の「追跡」（[ロット追跡タブ](trace.md)へ移動します） |

---

## 2. 画面の構成

```
[商品名・SKU・JANコードで検索...] [全カテゴリ▼] [全倉庫▼]

 商品名   SKU     JANコード      カテゴリ 合計在庫      販売定価 原価  操作
▶ 牛乳    ML-001  4901234567894  乳製品   20（2ロット）  ¥198   ¥130  [FEFO出庫][編集][削除]
▼ 食パン  BR-001  4912345678904  パン      3（1ロット）  ¥150    ¥90  [FEFO出庫][編集][削除]
   └ ロット一覧                                              [+ ロット追加]
      ロットNo   賞味期限  倉庫        在庫数  原価  操作
      20260703   今日まで  🟢販売倉庫    3    ¥118  [入庫][出庫][移動][追跡][編集][削除]
```

### 検索・絞り込み

| 項目 | 動作 |
|------|------|
| 検索欄 | **商品名・SKU・JANコード**の部分一致。大文字小文字は区別しません |
| カテゴリ | 選んだカテゴリの商品だけ表示 |
| 倉庫 | **その倉庫にロットがある商品**だけ表示。さらに展開したロット一覧も、その倉庫のロットだけになります |

3つの条件は同時に効きます（すべてを満たす商品が表示されます）。
条件に合う商品がないときは「商品が見つかりません」と表示されます。

> 倉庫で絞り込んでも、**「合計在庫」の数字は全倉庫の合計のまま**です（ロット数の表示も同様）。
> 倉庫ごとの在庫数を見たいときはダッシュボードの「倉庫別在庫」を使ってください。

### 並べ替え

見出しをクリックすると並べ替わります。同じ見出しをもう一度クリックすると昇順・降順が入れ替わります（▲＝昇順、▼＝降順）。

- 並べ替えできる列：**商品名 / SKU / JANコード / カテゴリ / 販売定価 / 原価**
- 並べ替えできない列：合計在庫、操作
- 初期状態は商品名の昇順です。

### 行の色

商品行・ロット行は状態に応じて色が付きます。上にあるものが優先されます。

| 色 | 意味 |
|----|------|
| 赤 | 期限切れのロットがある（商品行）／期限切れのロット（ロット行） |
| 黄 | 期限まで7日以内のロットがある／期限まで7日以内のロット |
| 青 | 合計在庫が発注点以下（商品行のみ） |

賞味期限欄のバッジは、期限切れ＝「期限切れ」、当日＝「今日まで」、7日以内＝「N日後」、
8日以上先＝日付そのまま、期限なし＝「—」と表示されます。

## 3. 商品行の操作

### FEFO出庫

**この画面の要となる機能です。**「どのロットから出すか」を人が選ばずに、期限の近いものから自動で引き当てます。
詳しくは [fefo.md](fefo.md) を参照してください。合計在庫が0の商品ではボタンが押せません。

### 編集

商品の登録内容（商品名・SKU・JANコード・カテゴリ・最低在庫数・販売定価・原価）を直すダイアログが開きます。
**在庫数はここでは変えられません**（在庫はロットに付いているためです）。

| 項目 | 入力ルール |
|------|-----------|
| 商品名 | 必須 |
| SKU | 必須。重複チェックはしていないので、運用側で一意にしてください |
| JANコード | 任意。数字8桁または13桁。全角で入れても半角に直り、ハイフンや空白は自動で取り除かれます |
| カテゴリ | 必須。カテゴリマスタに登録済みのものから選びます |
| 最低在庫数 | 発注点。合計在庫がこの数**以下**になると要発注として警告されます |
| 販売定価 / 原価 | 円単位。販売定価＝売価集計に使用。原価は「ロットに原価が設定されていないときの既定値」で、在庫金額・差異金額・廃棄ロスの計算に使います（ロットごとに原価があればそちらが優先されます） |

### 削除

商品と、その商品が持つ**すべてのロット（在庫）が消えます。** 確認ダイアログが出ます。

- 在庫が残っていたロットは、**「調整出庫（備考：商品削除）」として1ロットにつき1件、帳票に記録されます。**
  在庫が勝手に消えたように見えないための仕様です。
- 削除した商品は元に戻せません。

## 4. ロット一覧（商品行を展開）

商品行のどこか（操作ボタン以外）をクリックすると、その商品のロット一覧が下に開きます。もう一度クリックで閉じます。
複数の商品を同時に開いておけます。

ロットが1件もない場合は「ロットがありません。「+ ロット追加」から追加してください。」と表示されます。

### + ロット追加 / 編集（ロットの登録内容）

| 項目 | 入力ルール |
|------|-----------|
| 賞味期限 | 任意。**入力するとロットNoが `YYYYMMDD` の形で自動生成**されます（ラベル等、期限のない商品は空でOK） |
| ロットNo | 必須。**半角数字8桁**。数字以外は入力できず、8桁でないと保存時にエラーになります。手入力で上書きも可能です |
| 在庫数 | そのロットの在庫数 |
| 原価（仕入単価） | 任意。円単位。初期値は商品の現在の原価。**初期値のまま保存すると値を固定しません**（あとで商品の原価を変えれば追従します）。数値を変えて保存すると、そのロット専用の原価として固定されます |
| 倉庫 | 保管する倉庫。初期値は「販売倉庫」 |

- **追加**したとき：在庫数が1以上なら「入荷（備考：ロット追加）」として帳票に記録されます。
- **編集**したとき：変更内容に応じて帳票に記録されます。
  - 倉庫を変えた → 「移動」1件（変更前の在庫数で記録）
  - 在庫数を変えた → 増加なら「調整入庫」、減少なら「調整出庫」（備考：ロット編集）
  - 両方変えた → 「移動してから数量を調整した」とみなして2件記録されます
- ロットNoは自動生成のため、**同じ期限のロットを分けて登録すると同じロットNoになり得ます。** システムは
  ロットNoではなく内部IDで区別しているので動作に問題はありませんが、Excelインポートは
  SKU＋ロットNoで突き合わせるため、重複していると先に見つかった1件だけが更新されます。

### 入庫 / 出庫

ロット単位で在庫数を増減します。

| | 入庫 | 出庫 |
|---|------|------|
| 選べる区分 | 入荷 / 調整入庫 | 売上出庫 / 調整出庫 / 廃棄 |
| 数量の上限 | なし | そのロットの在庫数まで |
| ボタンの状態 | 常に押せる | 在庫0のロットでは押せない |

確定すると、選んだ区分でそのまま帳票に記録されます（備考は空欄）。倉庫はロットの倉庫が記録されます。

### 移動

ロットの在庫を別の倉庫へ動かします。

| 項目 | 内容 |
|------|------|
| 移動元 | そのロットの現在の倉庫（表示のみ） |
| 移動先 | 現在の倉庫以外から選択 |
| 移動数量 | 1〜そのロットの在庫数。初期値は全量 |

- **全量を移動**した場合：ロットの倉庫が書き換わるだけです（ロットは増えません）。
- **一部だけ移動**した場合：元のロットの在庫が減り、移動先の倉庫に**同じロットNoの新しいロットが作られます**。
  そのため、同じ商品に同じロットNoのロットが2つ並ぶことがあります（倉庫が違うので別のかたまりです）。
- どちらの場合も、帳票には「移動」1件（備考：倉庫移動）として `移動元 → 移動先` が記録されます。
- 倉庫が1つしか登録されていない場合は移動先が選べず、移動ボタンは押せません。

### 追跡

そのロットが「いつ入って、どこを経由して、いつ出たか」を時系列で表示します。
押すと[ロット追跡タブ](trace.md)に切り替わり、そのロットを選んだ状態で開きます。
**在庫は動きません**（見るだけの機能です）。

一部移動で同じロットNoが複数の倉庫に分かれている場合、どちらのロット行から押しても
同じ追跡結果（両方の倉庫の在庫を合わせたもの）が表示されます。

### 削除（ロット）

そのロットが消えます。確認ダイアログが出ます。
在庫が残っていた場合は「調整出庫（備考：ロット削除）」として帳票に記録されます。

## 5. よくある操作の流れ

**入荷したとき**
1. 在庫一覧で商品を検索し、行をクリックして展開
2. 「+ ロット追加」→ 賞味期限を入れる（ロットNoは自動）→ 数量と倉庫を入れて保存
3. 帳票に「入荷」が1件残る

*同じロットNo・同じ倉庫に追加入荷したときは、新しいロットを作らずに既存ロット行の「入庫」から数量を足す方が
ロットが分散しません。*

**出荷するとき**
1. 商品行の「FEFO出庫」→ 数量を入れる → プレビューで引当先を確認 → 出庫
2. 期限の近いロットから自動的に減り、帳票に引当ロットごとの「売上出庫」が残る

**期限切れを処分するとき**
1. 該当ロット行の「出庫」→ 区分「廃棄」→ 全量を入力
2. 在庫が0になったロットは、以後アラートに残るので削除する
