# FEFO出庫（在庫一覧タブの機能）

在庫一覧タブの商品行にある「FEFO出庫」ボタンから開く画面の仕様です。

FEFO＝**First Expired, First Out**（先に期限が来るものから先に出す）。
「牛乳を12個出す」とだけ指定すれば、**どのロットから何個引くかはシステムが決めます。**
期限の近い在庫を売れ残らせないための機能です。

> 開発者向けの詳細（アルゴリズム・関数構成）は [../fefo-feature.md](../fefo-feature.md) にあります。

---

## 1. 画面の構成

```
FEFO出庫
牛乳（ML-001）
賞味期限の近いロットから自動で引き当てます。（対象在庫: 20）

  倉庫       [全倉庫 ▼]
  出庫区分   [売上出庫 ▼]
  出庫数量   [ 12 ]
  ☐ 期限切れロットも引当対象にする

  引当プレビュー
   ロットNo   賞味期限  倉庫        引当数  引当後
   20260703   3日後     🟢販売倉庫    10      0
   20260707   7日後     🟢販売倉庫     2      8

                              [キャンセル] [出庫]
```

| 入力項目 | 説明 |
|----------|------|
| 倉庫 | 「全倉庫」なら倉庫を問わず期限順に引きます。倉庫を選ぶと**その倉庫のロットだけ**が対象になります |
| 出庫区分 | 売上出庫 / 調整出庫 / 廃棄。帳票にこの区分で記録されます |
| 出庫数量 | 出したい合計数量。ロットごとの内訳を入力する必要はありません |
| 期限切れロットも引当対象にする | 通常はOFF。ONにすると期限切れの在庫も引当に含めます（廃棄処理などで使用） |
| 対象在庫（見出し部分） | いま選んでいる倉庫の合計在庫。全倉庫なら商品全体の合計 |

---

## 2. 引き当ての順番

対象になるロットを次の順に並べ、先頭から順に必要数まで引きます。

1. **賞味期限が早いもの順**
2. 賞味期限のないロット（ラベル等）は**最後**
3. 期限が同じ場合はロットNo順（それも同じなら内部ID順）

対象から外れるロット：

- 在庫数が0のロット
- 倉庫を指定したときの、**他の倉庫**のロット
- 期限切れのロット（「期限切れロットも引当対象にする」がOFFのとき）

---

## 3. 引当プレビュー

入力を変えるたびに、**実際に出庫したときとまったく同じ計算結果**が表として表示されます。
「確定したら別のロットから引かれていた」ということは起こりません。

| 列 | 意味 |
|----|------|
| ロットNo / 賞味期限 / 倉庫 | 引き当て先のロット |
| 引当数 | そのロットから引く数量 |
| 引当後 | 出庫後にそのロットに残る数量 |

プレビューの下に出ることがあるメッセージ：

- **「在庫が N 不足しています。」** — 対象在庫が足りません。この状態では**出庫ボタンが押せません。**
  数量を減らすか、倉庫の指定を「全倉庫」に広げるか、期限切れを対象に含めてください。
- **「期限切れロットの N は引当対象から除外しています。」** — 期限切れの在庫があり、引当から外していることの通知です。
  数が足りているならそのまま出庫して構いません。

---

## 4. 出庫を実行すると

1. 引き当てられたロットの在庫が、それぞれの引当数だけ減ります。
2. **引き当てたロットごとに1件ずつ**、選んだ出庫区分で帳票に記録されます（備考：`FEFO出庫`、倉庫はそのロットの倉庫）。
   3ロットに分かれて引き当てられたなら、帳票には3行残ります。
3. 結果のお知らせダイアログが出ます（例：「牛乳 を 12 出庫しました（2ロットから引当）。20260703: 10、20260707: 2」）。

---

## 5. 注意点

- **在庫が足りないときは出庫できません。** 部分的に出庫する仕様ではありません。
- 出庫数量は整数として扱われます。
- ロットの在庫が0になっても、ロット自体は残ります（期限アラートに出続けるので、不要なら削除してください）。
- ロットを個別に指定して出したい場合は、この機能ではなくロット行の「出庫」ボタンを使ってください。
