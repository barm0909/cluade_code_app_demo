# 棚卸タブ

実地棚卸（実際に数えた在庫）をシステムに反映するための画面です。

**帳簿在庫**（システムが持っている数）と**実数**（人が数えた数）を並べて入力し、
差異のあるロットだけを最後にまとめて確定します。確定するまで在庫は1つも変わりません。

ロットが1件もないときは「ロットがありません。在庫一覧からロットを追加すると棚卸できます。」と表示されます。

---

## 1. 画面の構成

```
[商品名・SKU・ロットNoで検索...] [全カテゴリ▼] [全倉庫▼] [条件クリア] ☐差異のみ表示

カウント 3 / 5 ロット  一致 1  棚卸増 1  棚卸減 1  差異金額 -¥130
        [未入力を帳簿在庫で埋める][入力クリア][CSVエクスポート（棚卸表）][棚卸を確定（2件）]

 商品名  SKU     ロットNo   賞味期限  倉庫        帳簿在庫  実数  差異  差異金額
 牛乳    ML-001  20260703   3日後     🟢販売倉庫      10   [ 9]   -1   -¥130
 牛乳    ML-001  20260707   7日後     🟢販売倉庫      10   [10]    0     —
 食パン  BR-001  20260701   今日まで  🟢販売倉庫       3   [  ]    —     —
```

**1行＝1ロット**です。商品単位ではなくロット単位で数えます。

---

## 2. 実数の入力

- 「実数」欄に、実際に数えた数を入力します。
- **空欄＝未カウント**です。0を入力するのと空欄のままにするのは意味が違います
  （0＝「数えた結果0個だった」、空欄＝「まだ数えていない」）。
- マイナスや小数を入れても、0以上の整数に丸められます。
- 入力すると、その行の「差異」「差異金額」がすぐ計算されます。

| 行の状態 | 表示 |
|----------|------|
| 実数 > 帳簿在庫（棚卸増） | 差異が `+N`、行が強調表示 |
| 実数 < 帳簿在庫（棚卸減） | 差異が `-N`、行が強調表示 |
| 実数 = 帳簿在庫（一致） | 差異が `0` |
| 未カウント | 差異・差異金額が「—」 |

差異金額は `差異 × 原価` です（棚卸減はマイナス金額）。

---

## 3. 絞り込みと補助ボタン

| 機能 | 動作 |
|------|------|
| 検索欄 | 商品名・SKU・ロットNoの部分一致 |
| カテゴリ / 倉庫 | 対象ロットを絞り込み。**倉庫ごとに順番に数えるとき**に使います |
| 条件クリア | 絞り込みを解除（何か絞り込んでいるときだけ表示） |
| 差異のみ表示 | 実数を入力済みで、かつ帳簿在庫と違う行だけを表示。**確定前の最終確認**に使います |
| 未入力を帳簿在庫で埋める | **いま表示中の行のうち未入力のもの**を帳簿在庫と同じ数で埋めます（入力済みの数は上書きしません） |
| 入力クリア | 入力した実数をすべて消します（在庫は変わりません） |
| CSVエクスポート（棚卸表） | 表示中の行を `棚卸表_YYYY-MM-DD.csv` に出力 |

> **「未入力を帳簿在庫で埋める」の使い方**
> 「数えて差異があったものだけ入力し、残りは帳簿どおりだった」という進め方のためのボタンです。
> ただし、**絞り込み中に押すと表示されている行だけが対象**になります。全ロットを一括で埋めたい場合は、
> 先に「条件クリア」で絞り込みを解除してください。

**CSVの中身**（未カウントの行は実数・差異が空欄で出るので、印刷してカウント用紙としても使えます）

```
商品名,SKU,ロットNo,賞味期限,倉庫,帳簿在庫,実数,差異,差異金額
牛乳,ML-001,20260703,2026-07-03,販売倉庫,10,9,-1,-130
食パン,BR-001,20260701,2026-07-01,販売倉庫,3,,,
```

## 4. 集計バー（表の上）

| 表示 | 意味 |
|------|------|
| カウント N / M ロット | 実数を入力済みのロット数 / 対象ロット数。絞り込み中は `絞込件数（全件数）` の形で表示 |
| 一致 | 実数＝帳簿在庫だったロット数 |
| 棚卸増 | 実数＞帳簿在庫のロット数 |
| 棚卸減 | 実数＜帳簿在庫のロット数 |
| 差異金額 | 差異金額の合計（原価ベース） |

> **集計と確定は、絞り込みに関係なく「入力済みのすべてのカウント」が対象です。**
> 倉庫Aを数えたあとに倉庫Bへ絞り込みを変えても、倉庫Aの入力は消えず、集計にも残ります。

---

## 5. 棚卸を確定

「棚卸を確定（N件）」を押すと、確認ダイアログに次の内容が表示されます。

```
差異のある2件のロットを実数に更新し、入出庫帳票に「棚卸」として記録します。
（棚卸増 1件 / 棚卸減 1件、差異金額 -¥130）
よろしいですか？
```

確定すると、

1. **差異のあるロットだけ**、在庫数が実数に置き換わります（一致していた行は何もしません）。
2. 差異が増加なら「調整入庫」、減少なら「調整出庫」として、**1ロットにつき1件**帳票に記録されます（備考：`棚卸`）。
3. 入力した実数がすべてクリアされ、「差異のみ表示」も解除されます。
4. 「N件のロットの在庫数を更新しました。」と表示されます。

**注意点**

- 差異が1件もないときは、確定ボタンは押せません。
- 確定は**元に戻せません。**取り消したい場合は、在庫一覧タブから手動で戻す操作が必要です。
- 確定するのは絞り込みに関係なく**入力済みのカウントすべて**です。画面に見えていない行も反映されます。
- 確定前に画面を再読み込みすると、入力した実数は失われます（実数は確定するまでサーバーに保存されません）。

---

## 6. 想定する運用の流れ

1. 棚卸タブを開き、倉庫で絞り込む
2. 「CSVエクスポート（棚卸表）」で用紙を印刷し、現場で数える
3. 数えた結果を「実数」欄に入力する（帳簿どおりだったものは「未入力を帳簿在庫で埋める」でまとめて）
4. 「差異のみ表示」で差異を確認し、数え直しが必要なものを再確認
5. 「棚卸を確定」→ 在庫が実数に揃い、帳票に記録が残る
