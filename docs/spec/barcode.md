# バーコード読み取り

商品の **JANコード（8桁・13桁のバーコード）** を読み取って、商品を選ぶ・数える操作を速くする機能です。
専用のタブはなく、次の画面に「バーコードの読み取り欄」があります。

| 画面 | 読み取るとどうなるか |
|------|----------------------|
| 在庫一覧 | その商品だけに絞り込み、ロットを開いた状態にする |
| 棚卸（スキャン数え） | **1つ読むたびに、その商品のロットの実数が 1 増える** |
| 売上登録（売上管理タブ） | その商品を選ぶ。同じ商品を続けて読むと数量が 1 ずつ増える |
| FEFO出庫（在庫一覧の商品行） | 開いている商品なら数量が 1 増える。別の商品なら知らせるだけ |
| 入荷予定 | その商品の未入荷の予定が1件なら入荷画面を開く。複数なら一覧をその商品に絞り込む |

**JANコードで分かるのは「どの商品か」だけです。** ロットや賞味期限はバーコードに入っていないので、
出庫は今までどおり期限の近いロットから自動で引き当て、棚卸ではどのロットを数えるかを選びます。

---

## 1. 読み取り方は3通り

読み取り欄（点線の枠の入力欄）はどれも同じ使い方です。

1. **バーコードスキャナー（USB・Bluetooth）**：読み取り欄をクリックしてからバーコードを読むだけです。
   スキャナーはキーボードとして数字を入力して最後に Enter を押すので、特別な設定は要りません
2. **手入力**：JANコードを打って Enter。JANのない商品は **SKU** を打って Enter でも呼び出せます
3. **カメラ**：「カメラで読む」を押すと、スマホ・タブレット・PC のカメラが起動します。バーコードを白い枠の中に写すと読み取ります
   - カメラは **https のページ**でしか使えません（公開している本番の画面なら使えます）
   - 初めて使うときはブラウザがカメラの許可を聞いてくるので「許可」してください
   - 同じバーコードを写し続けても、1.5秒の間は二重に読み取りません
   - 棚卸のスキャン数えでは、読み取っても閉じずに次を待ちます（終わったら「閉じる」）。それ以外は1つ読むと閉じます

読み取り欄のすぐ下には、**その画面で読み取ると何が起きるか** が小さな灰色の文字で出ています
（例：在庫一覧なら「スキャンすると：その商品だけを一覧に表示し、ロットを開きます」）。
読み取ると同じ場所に結果が出ます（緑＝成功、赤＝見つからないなど、青＝続けて操作してほしいことの案内）。
結果が出ている間も、読み取り欄にマウスを乗せれば説明を見られます。カメラの画面にも同じ説明が出ます。

| 表示 | 意味 |
|------|------|
| 未登録のJANコードです（4901…） | そのJANを登録した商品がありません。商品マスタでその商品にJANコードを登録してください |
| JANコードとして読み取れませんでした | 桁数か最後の1桁（チェックデジット）が合いません。読み取りなおしてください |
| 「○○」に一致する商品がありません | 手入力した文字が JAN にも SKU にも一致しません |

---

## 2. 棚卸のスキャン数え

棚卸タブの上にある「スキャン数え」の欄で、**商品を1つ手に取るたびにバーコードを読む** と実数が 1 増えます。
数え終わったら、いつもどおり表で差異を確認して「棚卸を確定」します。

- 未カウントのロットは 0 から数え始めます。表の実数を手で直しても構いません（スキャンはその数に +1 します）
- **ロットが複数ある商品** は、最初に読んだときに「どのロットを数えますか？」とロットのボタン（ロットNo・期限・倉庫・帳簿在庫）が出ます。
  選ぶとそのロットに +1 し、**同じ商品の次からは同じロットに数えます**
- 別のロットを数えるときは「数えるロットを選び直す」を押してから読みます
- 倉庫・カテゴリで絞り込んでいると、その範囲のロットだけが対象です。倉庫ごとに数えるときは、先に倉庫を絞り込むとロットを選ぶ手間が減ります
  （キーワードの絞り込みは関係しません）

---

## 3. 売上登録・FEFO出庫・入荷

- **売上登録**：読み取った商品が選ばれ、数量 1 になります。同じ商品を続けて読むと数量が増えます。資材は売上にできないので選ばれません
- **FEFO出庫**：開いている商品を読むたびに数量 +1。別の商品を読んでも切り替わりません（その商品の行から開き直してください）
- **入荷予定**：届いた商品を読むと、その商品の未入荷（一部入荷を含む）の予定を探します。1件ならそのまま入荷画面が開き、
  複数あれば一覧をその商品に絞り込むので、入荷する予定の「入荷」を押します

---

## 4. 商品マスタ：JANコードの検証とバーコード表

- JANコードは **最後の1桁（チェックデジット）** まで確かめます。打ち間違えると
  「JANコードの最後の1桁（チェックデジット）が合いません」と出て保存できません
- 「バーコード表」ボタンで、JANコードを登録した商品のバーコードを一覧で表示・印刷できます
  - **スキャナーがなくても読み取りを試せます**：バーコード表をPCの画面に出し、スマホで本番の画面を開いて「カメラで読む」で写します
  - 印刷して値札・棚札にも使えます（JANコード未登録の商品は載りません）

---

## 5. 注意点

- ロット番号・賞味期限を含むバーコード（GS1-128 など）や QRコードは読み取れません
- 同じJANコードを複数の商品に登録すると、先に見つかった商品になります（JANコードは商品ごとに別にしてください）
- スキャナーで読むときは、読み取り欄にカーソルがある状態にしてください（別の欄にあると、そこに数字が入ります）
