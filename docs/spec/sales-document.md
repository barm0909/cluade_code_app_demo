# 納品書・請求書タブ

得意先に渡す **納品書** と **請求書** を作って印刷する画面です。もとになるのは売上管理に記録された売上
（入出庫帳票の「売上出庫」）で、ここで新しく売上を登録したり金額を書き換えたりすることはできません。

発行した書類は記録として残り、あとから同じ内容で再表示・再印刷できます（発注書と発注履歴の関係と同じです）。

**この画面で在庫が動くことはありません。** 発行しても取り消しても、入出庫帳票には何も記録されません。

---

## 1. 画面の構成

```
[+ 納品書を作成] [+ 請求書を作成] [検索...] [種類▼] [得意先▼] [発行日 開始 〜 終了] [条件クリア]
─────────────────────────────────────────────────────────────
2件                                   [CSVエクスポート（納品書・請求書）]
─────────────────────────────────────────────────────────────
発行日      種類    書類番号        得意先         対象                     明細  金額（税込）  操作
2026-11-17  請求書  I20261117-001   さくらカフェ   2026-10-01 〜 2026-10-31   3   ¥12,960     [再表示][取消]
2026-11-17  納品書  D20261117-001   みどりストア   2026-11-17                 2   ¥  583      [再表示][取消]
```

一覧は **発行した操作の新しい順** に並び、**1枚の書類 = 1行** です。

### 絞り込み

| 条件 | 対象 |
|------|------|
| キーワード | 書類番号・得意先名、または書類に載っている明細のいずれかの商品名・SKU の部分一致 |
| 種類 | 納品書 / 請求書 |
| 得意先 | 得意先マスタに登録された得意先 |
| 期間 | 書類の発行日（開始日・終了日とも、その日を含む） |

---

## 2. 納品書を作る

「+ 納品書を作成」を押すと作成画面が開きます。

| 入力欄 | 内容 | 初期値 |
|--------|------|--------|
| 得意先 | 書類の宛先。売上のある得意先が先頭に並びます。取引停止の得意先も選べます（過去の売上の書類を出すため） | 売上のある得意先の先頭 |
| 納品日 | この日の売上を載せます | その得意先の、まだ納品書に載っていない売上のうち最新の日（なければ今日） |
| 発行日 | 書類に印字する日付 | 今日 |
| 発行元（自社）情報 | 自社名・住所・電話番号・担当者・登録番号・振込先 | 前回入力した内容（初めてなら発注書の「発注元」の内容） |

得意先と日付を選ぶと「載せる売上」に候補が並び、下に印刷される紙面のプレビューが出ます。

- **同じ日・同じ商品・同じ単価・同じ税率の売上は1行にまとめます。**
  （期限の近いロットから出庫すると、1回の売上でもロットごとに帳票が分かれるため）
- チェックを外した行は紙面に載りません。既定はすべてチェック済みです
- 販売単価を入れずに登録した売上は「定価で計算」と表示され、商品の販売定価で金額を出します（売上管理と同じ扱い）
- **得意先を指定せずに登録した売上は書類にできません**（宛先がないため）
- **売上返品は請求書にだけ載ります。** 「返品」の印つきのマイナスの行として、請求額から差し引きます。
  納品書には載せません（[returns.md](returns.md)）

「発行して印刷」を押すと、書類番号を付けて記録し、ブラウザの印刷画面を開きます。PDFにしたいときは
印刷画面で「PDFに保存」を選んでください。

## 3. 請求書を作る

「+ 請求書を作成」で開く画面は納品書とほぼ同じで、日付の欄だけが違います。

| 入力欄 | 内容 | 初期値 |
|--------|------|--------|
| 対象期間（開始・終了） | この期間の売上を載せます | 得意先の締め日から決まる、今日以前で直近の締めの期間（例: 20日締めなら前月21日〜今月20日）。都度請求の得意先は先月の1日〜末日 |
| お支払期限 | 紙面に印字する期限 | 得意先の支払条件から計算（例: 翌月10日払いなら、対象期間の終了日の翌月10日） |

得意先を選ぶと、欄の下に「20日締め・翌月10日払い」のように得意先の締め日・支払条件が表示されます
（得意先マスタで設定します。[master.md](master.md)）。

請求書の紙面には、納品書に加えて **ご請求金額・繰越欄・対象期間・お支払期限・振込先** が載り、
明細には納品日の列が付きます。

### 繰越欄

請求書には前回からの繰越を載せます（「締め請求」で作る請求書も同じです）。

| 前回御請求額 | 御入金額 | 繰越額 | 今回御買上額（税込） | 今回御請求額 |
|---|---|---|---|---|
| ¥50,000 | ¥48,000 | ¥2,000 | ¥30,000 | ¥32,000 |

- **繰越額**：それまでに発行したこの得意先の請求書の残高の合計から、どの請求書にも充てていない入金（前受）を引いた額。
  入金管理タブの残高と同じ数え方です（前受の方が多いとマイナスになります）
- **御入金額**：前回の請求書の発行日の翌日から、今回の発行日までに登録した入金（振込手数料を含む）
- **前回御請求額**：繰越額 ＋ 御入金額 で計算します。入金をあとから過去の日付で登録した場合などは、
  前回の請求書に印字した額と一致しないことがあります
- **今回御請求額**：繰越額 ＋ 今回御買上額。紙面の「ご請求金額」はこの額です
- 繰越は「発行して印刷」を押した時点の請求書・入金で計算し直して記録します

入金管理で消し込む対象になる請求額は **今回御買上額だけ** です（繰越額は前の請求書の残高なので、二重に数えないため）。
この機能より前に発行した請求書と納品書には繰越欄は出ません。

## 3-2. 締め請求（まとめて請求書を作る）

「締め請求」ボタンで開きます。**締め日を1つ選ぶと、その日が締め日にあたる得意先の請求書をまとめて作れます。**

| 入力欄 | 内容 | 初期値 |
|--------|------|--------|
| 締め日 | この日が締め日の得意先が対象になります | 取引中の得意先の締め日のうち、今日以前で一番新しい日 |
| 発行日 | 書類に印字する日付 | 今日 |
| 発行元（自社）情報 | 請求書の作成と共通（この端末に保存） | 前回入力した内容 |

対象の得意先が1行ずつ並びます。

| 列 | 中身 |
|----|------|
| 得意先 | 得意先名と締め日・支払条件。「発行済み（書類番号）」「請求する売上なし」の印 |
| 対象期間 | 前月の締め日の翌日 〜 締め日。前回以前の請求漏れがあれば「前回以前 n件」 |
| 今回御買上額 | 載せる売上の税込合計と行数 |
| 繰越額・今回御請求額 | 上の繰越欄と同じ計算 |
| お支払期限 | 支払条件から計算した日 |

- **載せる売上は、締め日までの売上のうち、まだ請求書に載っていないものすべて** です。対象期間より前の売上
  （前回の締めで請求し漏れたもの）も含め、紙面の行に「前回以前」の印を付けます。締め日より後の売上は次回に回ります
- 返品は差し引きます（個別の請求書と同じ）
- **都度請求の得意先は対象外** です（1枚ずつ「+ 請求書を作成」で作ります）
- 取引停止の得意先は、請求する売上か繰越があるときだけ並びます
- 請求する売上がない得意先と、この締め日の請求書をすでに発行した得意先は選べません
- チェックを外した得意先は発行しません。既定は選べる得意先すべてです

下に印刷される紙面のプレビューが得意先の数だけ並びます。「n件を発行して印刷」を押すと、書類番号を続き番号で付けて
すべて記録し、印刷画面を開きます（得意先ごとに改ページします）。

## 4. 紙面に載る内容

適格請求書（インボイス）の記載事項に合わせています。

- 宛先（得意先名・住所・担当者）
- 書類番号・発行日、発行元（自社名・住所・連絡先・**登録番号**）
- 明細（納品日・商品名・SKU・数量・単価・金額）。**軽減税率（8%）の商品には「※」** を付けます
- 税率ごとの対象金額と消費税額（例：「8%対象（軽減税率） ¥600（消費税 ¥48）」）
- 小計（税抜）・消費税・合計（税込）

登録番号は空欄なら紙面に載りません。入力する場合は **「T」＋13桁の数字** にしてください（形式が違うと発行できません）。

### 消費税の計算（売上管理と数円ずれることがあります）

書類の消費税は **税率ごとに税抜金額を合計してから、1回だけ四捨五入** します（1枚の請求書につき
税率ごとに1回端数処理する、インボイス制度のルール）。

売上管理は **売上の明細1行ごとに** 四捨五入して足し上げるので、同じ売上でも消費税が数円違うことがあります。
請求する金額としては書類の方が正しい値です。

## 5. 二重発行の防止

**一度ある書類に載せた売上は、同じ種類の書類にはもう載せられません。** 作成画面では「発行済み（書類番号）」と
表示され、チェックできなくなります。

- 納品書と請求書は別に数えます。納品書を出した売上を、月末に請求書にまとめることはできます
- 間違えて発行したときは、一覧の「取消」で書類を取り消してください。載っていた売上は、ふたたび選べるようになります
- **入金を充てた請求書は取り消せません**（取消ボタンが押せません）。先に「入金管理」タブの入金履歴から入金を削除してください（[receivables.md](receivables.md)）
  （すでに相手に渡した紙は回収・破棄してください）

## 6. 書類番号

`種類の記号` ＋ `発行日` ＋ `-` ＋ `その日の連番3桁` です。

| 種類 | 例 |
|------|----|
| 納品書 | `D20261117-001` |
| 請求書 | `I20261117-001` |

連番は、同じ種類・同じ発行日の書類で使われている一番大きい番号の次になります。

## 7. 再表示・再印刷

行の「再表示」を押すと、**発行したときと同じ内容** の書類が開き、「印刷」でもう一度印刷できます。

- 得意先名・住所、商品名、発行元の情報は **発行した時点の記録** です。あとでマスタを直しても変わりません
- 再印刷は新しい発行ではないので、一覧も書類番号も増えません

## 8. CSVエクスポート

「CSVエクスポート（納品書・請求書）」で、**絞り込み後の書類を明細1行ごと** に
`納品書・請求書_YYYY-MM-DD.csv` へ出力します。

```
種類,書類番号,発行日,得意先,対象期間（開始）,対象期間（終了）,お支払期限,納品日,商品名,SKU,数量,単価（税抜）,金額（税抜）,税率
請求書,I20261117-001,2026-11-17,さくらカフェ,2026-10-01,2026-10-31,2026-11-30,2026-10-19,食パン,BR-001,4,150,600,8%
```

## 9. 注意点

- 入金の記録・消し込みは「入金管理」タブで行います（[receivables.md](receivables.md)）
- 締めの確定（締めた期間の売上を修正できなくすること）はありません。締めたあとに売上を登録・返品すると、次回の請求書に「前回以前」として載ります
- 売上がなく繰越だけの得意先の請求書は作れません（明細が1件以上必要です）
- 「発行して印刷」を押した時点で発行したものとして記録します（印刷画面でキャンセルしても記録は残ります。不要なら「取消」してください）
- 発行元（自社）情報は **この端末のブラウザに保存** されます。別のパソコンでは入力し直しが必要です
- 取り消した書類の番号は、同じ日にもう一度発行すると再び使われることがあります
- ヘッダーの「リセット」を押すと、帳票と一緒に発行した書類の記録もすべて消えます
- **誰が発行したかは記録されません**（ログイン機能がないため）
