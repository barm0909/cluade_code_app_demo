# 在庫分析タブ

**「どの商品がよく出ているか」「在庫を何日分持っているか」「動いていない在庫はどれか」**を
見るための画面です。入出庫帳票に残っている**出庫の記録**と、いまの在庫を突き合わせて計算します。

ダッシュボードが「いま手を打つべきもの（期限・欠品）」を見る画面なのに対し、
この画面は**もう少し長い目で在庫の持ち方を見直す**ための画面です。

この画面で在庫が動くことはありません。**ひとつだけ在庫以外を変える操作**として、
商品の「発注点（最低在庫数）」をまとめて更新する機能があります（後述）。

---

## 1. 画面の構成

```

■ ABC分析（出庫金額の構成比）          集計期間[直近90日▼]
  [商品名・SKUで検索...][カテゴリ▼][ABCランク▼]  [CSVエクスポート（在庫分析）]

  ランク 商品名 SKU カテゴリ 在庫数 在庫金額 期間出庫数 出庫金額 構成比 回転率 在庫日数 最終出庫
```

### 上部のサマリ

| 項目 | 意味 |
|------|------|
| 在庫金額（原価） | いま持っている在庫の金額 |
| 期間の出庫金額 | 集計期間に出ていった在庫の金額 |
| 在庫日数 | 今の出庫ペースが続いた場合、いまの在庫が何日分にあたるか |
| Aランク商品 | よく出ている商品の数（B・Cの数も併記） |
| 滞留在庫 | 動いていない在庫の金額と商品数 |

## 2. 出庫の数え方（すべての集計の土台）

この画面でいう**出庫**は、入出庫帳票の次の3つの合計です。

- 売上出庫
- 調整出庫
- 廃棄

**倉庫間の移動は数えません**（倉庫を移しただけで在庫は減っていないため）。入庫も数えません。

集計期間は **直近30日 / 90日 / 180日 / 365日**から選べます（最初は90日）。
「今日を含む直近N日」なので、90日を選ぶと89日前から今日までが対象です。

> **ひとつだけ例外があります。**「最終出庫」の日付だけは集計期間で区切らず、記録の最初までさかのぼって探します。
> そうしないと「200日前に出たきり」と「一度も出ていない」が区別できないためです。

## 3. ABC分析

**出庫金額の大きい商品から順に並べ、上位からの累計で3つのランクに分けます。**
「売上（出庫）の大半を占めているのはどの商品か」を知るための、在庫管理では定番の分け方です。

| ランク | 条件 | 見方 |
|--------|------|------|
| **A** | 累計で上位70%までに入る商品 | 主力。欠品させてはいけない。発注点は余裕を持たせる |
| **B** | 累計90%までに入る商品 | 標準的な管理でよい |
| **C** | それ以降 ＋ 期間中に出ていない商品 | 在庫を持ちすぎていないか見直す対象 |

- 境目にまたがる商品は**上のランク**に入ります。
- 期間中に一度も出ていない商品は、必ず **C** になります。
- 期間中の出庫が全商品で0件のときは、全部Cになります。

### 各列の意味

| 列 | 計算 |
|----|------|
| 在庫数 / 在庫金額 | いまの在庫。金額は**ロットごとの原価**（未入力なら商品の原価）で計算 |
| 期間出庫数 | 集計期間の出庫の合計。廃棄が含まれる場合は「（廃棄N）」と併記 |
| 出庫金額 | `期間出庫数 × 商品の現在の原価` |
| 構成比 | その商品の出庫金額 ÷ 全体の出庫金額（バーの上の数字）。マウスを乗せると累計が出ます |
| 回転率 | `期間出庫数 ÷ いまの在庫数`。期間中に在庫が何回入れ替わった計算になるか |
| 在庫日数 | `いまの在庫数 ÷ 1日あたりの出庫数`。今のペースで何日もつか。出庫がなければ `—` |
| 最終出庫 | 最後に出庫した日。一度もなければ「実績なし」 |

### 絞り込み

キーワード（商品名・SKU）／カテゴリ／ABCランクで絞り込めます。
**CSVエクスポートは絞り込んだ後の内容**が出ます。

## 4. 滞留在庫

**在庫が残っているのに、しばらく出ていない商品**の一覧です。金額の大きい順に並びます。

| 判定 | 内容 |
|------|------|
| 30日以上 / 60日以上 / 90日以上 | 最終出庫からの経過日数がこれ以上（最初は60日） |
| 出庫なし | 出庫の記録が一度もない商品（在庫があれば必ず滞留として出ます） |

- **在庫が0の商品は出てきません**（滞留しているのは「在庫」なので）。
- ここに出た商品は、値引き販売・用途変更・発注停止などの検討対象です。
  この画面から廃棄はできません（廃棄はダッシュボードまたは在庫一覧から行います）。

---

## 5. 発注点の見直し提案

商品ごとの**発注点（最低在庫数）**を、実際の出庫ペースに合わせて計算し直して提案します。

```
提案値 ＝ 1日あたりの出庫数 ×（仕入先の標準リードタイム ＋ 安全在庫日数）
          ※小数点以下は切り上げ。最低1
```

**考え方**：発注してから届くまでの間に売れてしまう数を切らさないために持つのが発注点です。
そこに「読み違えたときのための余裕」として安全在庫日数分を上乗せします。

| 項目 | 内容 |
|------|------|
| 1日あたり出庫 | 集計期間の出庫数 ÷ 期間の日数 |
| リードタイム | 直近の入荷予定で使った仕入先の標準リードタイム。仕入先が未設定・取引停止なら0日 |
| 安全在庫 | 画面で 3日分 / 7日分 / 14日分 から選ぶ（最初は7日分） |
| 差 | 提案値 − 現在の発注点。▲は引き上げ、▼は引き下げ |

### 提案に出てこない商品

| 商品 | 理由 |
|------|------|
| 集計期間に出庫がなかった商品 | 出庫0から計算すると発注点が下がり、**たまにしか出ない商品が欠品する**ため。こうした商品は滞留在庫のほうで見てください |
| 提案値が今の発注点と同じ商品 | 直す必要がないため |

### まとめて反映する

1. 反映したい行のチェックを入れる（「すべて選択」で全件）
2. **［選択したN件を反映］**を押す
3. 確認ダイアログで件数（引き上げ／引き下げの内訳）を確認して「更新する」

- 更新されるのは商品の**発注点だけ**です。在庫は動かないので、入出庫帳票には何も記録されません。
- 更新した発注点はそのまま **ダッシュボードの「要発注」「発注提案」の基準**になります。
  在庫分析で発注点を直す → ダッシュボードで発注する、という流れです。
- 商品マスタの発注点欄を手で直したのと同じ扱いなので、あとから個別に直しても構いません。
- **取り消しはできません。**元の値に戻したいときは商品マスタで入力し直してください。

---

## 6. 数字が実際とずれる場合

この画面の数字は帳票からの**概算**です。以下は仕様として割り切っています。

| 項目 | 割り切り |
|------|----------|
| 出庫金額 | 出庫した時点の原価は記録に残っていないため、**商品の現在の原価**を掛けています。原価を改定すると過去の出庫金額の表示も変わります |
| 回転率 | 本来は期間中の平均在庫で割りますが、過去の在庫推移を持っていないため**いまの在庫数**で割っています |
| 帳票を付け始める前の在庫 | 記録がないため出庫実績に数えられません。運用開始直後は数字が小さく出ます |
